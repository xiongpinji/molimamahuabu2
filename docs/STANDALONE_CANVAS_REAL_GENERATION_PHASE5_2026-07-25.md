# 独立自由画布真实生成闭环 Phase 5（2026-07-25）

## 目标

让 `/canvas/:id` 中的图片、视频、音频自由节点直接调用项目现有真实模型链路，不要求创建剧集或分镜；文本节点继续作为提示词与上下游输入。

## 范围与约束

- 仅增强独立画布模式，原 `/film/:id/canvas` 剧集画布行为保持不变。
- 复用现有 `POST /images`、`POST /videos`、`POST /audio/extract`、任务查询和项目素材接口，不新增模拟生成服务。
- 图片、视频请求必须携带当前项目的正整数 `drama_id`，不得伪造 `storyboard_id`；用户只需创建项目，不需另建剧集或分镜。
- 音频请求直接发送节点文本与所选 TTS 模型，不要求 `storyboard_id`。
- 节点必须保留模型、提示词、素材引用、生成结果和可恢复失败信息。
- 生成成功后自动写入项目素材库，并把结果 URL 回填节点。
- 已连接的上游图片或视频结果可作为下游生成参考；没有可用结果时不伪造引用。

## 任务拆分

### Task 1：自由节点生成协议与纯函数

- 标准化图片、视频、音频节点的持久化字段。
- 构造不含 `storyboard_id` 的真实请求体。
- 解析图片任务、视频任务和同步音频结果。
- 覆盖请求、结果、上游引用和失败恢复单测。

### Task 2：画布节点运行与配置 UI

- 节点配置窗口增加模型选择和类型专属参数。
- 节点卡片增加运行、素材库、结果预览和失败重试入口。
- 接入真实接口、轮询、节点状态和项目素材自动保存。
- 刷新后恢复模型、结果 URL 和最后失败信息。

### Task 3：回归与浏览器验收

- 独立画布聚焦测试与前端全量测试通过。
- 生产构建通过。
- 浏览器验证图片、视频、音频节点的配置与运行入口。
- 有有效模型凭据时验证真实任务、后端读回和产物；若凭据或余额阻塞，必须如实记录 `blocked`，不得把 UI 验证当作真实生成成功。

## 完成结果

- 图片、视频、音频自由节点已接入现有真实 API 路由，独立画布请求不携带 `storyboard_id`。
- 视频节点可读取直接手动上游图片结果，作为首帧和参考图。
- 节点配置、运行状态、结果 URL、任务 ID、生成失败、素材入库失败及重试状态均写入项目画布布局。
- 生成结果自动保存为 `category=canvas-result`、`storyboard_id=null` 的项目素材；同节点同结果使用单飞保护，避免并发重复入库。
- 画布布局保存已串行化，避免并发保存时旧响应覆盖较新节点状态。
- Playwright mock E2E：独立画布图片、视频、音频 3 项通过；原剧集画布回归 8 项通过。
- 前端 Node 测试 313 项通过，生产构建通过。

## 验证边界

- 浏览器 E2E 验证了真实前端交互、请求体、任务轮询、布局写回、素材入库和刷新恢复，但后端响应由测试桩提供。
- 当前未使用线上供应商密钥与余额生成真实媒体产物，因此真实供应商任务、后端产物读回和计费证据仍标记为 `blocked`，不能据此宣称模型端已完成实测。

## 验收标准

1. 图片、视频、音频节点均可单独选择模型并保存。
2. 三类节点均有明确运行态、成功态、失败态和重试入口。
3. 用户无需另建剧集或分镜；图片/视频请求使用当前项目的正整数 `drama_id`，音频请求不依赖分镜。
4. 成功结果在节点内可预览，且项目素材库存在对应记录。
5. 刷新画布后仍可恢复节点配置、结果与失败信息。
6. 下游节点只消费实际存在的上游结果 URL。
7. 原剧集画布测试无回归。

## 后续项

- 使用有效供应商密钥与余额完成图片、视频、音频真实产物、后端读回及计费证据验证。
- 素材自动入库时补充节点标题或结果文件名，避免后端使用“未命名”兜底。
