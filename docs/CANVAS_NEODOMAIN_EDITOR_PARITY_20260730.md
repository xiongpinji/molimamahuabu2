# 独立画布节点编辑器对齐验收

## 目标

在不调用参考站生成接口、不消耗参考站积分、不复制品牌资产和私有接口的前提下，将茉莉妈妈独立画布的节点交互、信息层级和编辑器呈现方式对齐参考站。

## 已确认的参考交互

- 单击节点只选中当前节点，并在节点正下方展开就地编辑器；编辑器跟随节点移动。
- 图片节点编辑器包含参考素材、提示词、模型、比例、清晰度、批量数量、积分预估和提交入口。
- 视频节点编辑器包含 `首尾帧`、`多图参考`、`动作模仿`、`全能参考`、`视频编辑` 模式条，参考图片按序号展示，并显示模型、清晰度、时长、比例、音频、积分预估和提交入口。
- 编辑器不是固定在视口上的通用弹窗；节点与编辑器应形成一个连续的视觉单元。
- 只有当前真实模型支持的能力可以操作；尚未接通的模式必须明确显示为不可用，不能伪造成功链路。

## 本阶段范围

- 只修改共享节点编辑器与对应回归测试。
- 图片、视频节点对齐参考站的模式条、素材序列、参数胶囊和积分入口。
- 文本、音频节点继续使用同一套就地编辑器外壳，不虚构参考站未观察到的专属能力。
- 保留现有真实上传、素材库、`@` 引用、连线引用、运行、失败写回与积分计算链路。

## 非目标

- 不复制参考站商标、图标文件、文案资产或私有 API。
- 不触发参考站生成任务。
- 不修改另一任务正在处理的图片节点工具栏与导演台文件。

## 验收标准

1. 选中图片或视频节点后，编辑器在节点正下方出现并随节点移动。
2. 视频模式可在“首尾帧”和“多图参考”之间切换，并将现有参考素材真实写入对应引用类型。
3. 视频参考图按 `图片1`、`图片2` 的序列显示缩略图。
4. 模型、分辨率、时长、比例、音频和预计积分在提交区直接可见。
5. 未开放模式显示不可用状态，不触发虚假操作。
6. 不点击生成按钮即可完成浏览器回归，不产生积分消耗。
7. 前端构建与定向浏览器测试通过。
