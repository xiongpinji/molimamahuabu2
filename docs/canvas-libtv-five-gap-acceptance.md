# 独立画布 LibTV 五项差距验收

范围仅限 `/canvas/local`、`/canvas/:id` 及其直接依赖的画布接口；禁止修改
`AccountAdmin`、`TenantConsole`、`BillingAdmin`、`AdminWorkspace*`。

## 1. 本地画布接入真实项目运行时

- `/canvas/local` 保留本地草稿能力，不伪造项目 ID。
- 用户明确选择项目并点击“接入项目”后，将本地自由节点和手工连线合并到项目画布。
- 合并不得覆盖项目原有节点；ID 冲突必须重映射，随后进入 `/canvas/:id`。
- 进入项目画布后使用与 `/canvas/:id` 相同的生成、任务轮询、素材入库和计费链。

## 2. 子图运行

- 支持运行当前节点及其下游、运行框选自由节点。
- 只沿合法的手工连线计算依赖，按拓扑顺序串行执行。
- 环路必须在提交模型任务前阻止；上游失败时停止剩余下游并回写失败。

## 3. 语义端口与节点契约

- 文本连线区分上下文、提示词、语音文本。
- 图片到视频可选择首帧、尾帧、普通参考、角色参考、风格参考。
- 不兼容的节点类型拒绝连线；契约随画布布局持久化。

## 4. 多参考素材管理

- 节点编辑器展示直接上游参考图预览、用途、顺序、启用状态和权重。
- 顺序决定首尾帧及普通参考的提交顺序；停用项不得进入生成请求。
- 参考项修改后随连线保存，刷新后保持。

## 5. 模型能力与计费

- 画布读取脱敏模型目录，不返回密钥、网关或管理员配置。
- 模型可声明比例、分辨率、时长、数量、最大参考图和音频支持能力。
- 编辑器只展示当前模型允许的参数；无声明时采用保守默认并标明由供应商校验。
- 已配置积分单价时显示本次预计积分，未配置时明确显示“以实际结算为准”。

## 交付门槛

- 纯函数单测覆盖契约、拓扑排序、环路、参考图映射、能力限制和本地合并。
- 前端构建通过；画布 E2E 覆盖项目接入、节点拖动、连线契约、参考图和子图入口。
- 不以 UI 出现代替真实后端任务、结果 URL、素材入库和失败回写证据。
