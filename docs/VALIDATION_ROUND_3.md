# LibTV 画布 UI 首轮验证记录

日期：2026-07-15
范围：仅验证 “茉莉妈妈短剧制作平台” 的画布工作区 UI 与交互壳层，不调用任何付费模型。

## 已完成

- 深色浮层式画布顶栏，保留工作区 / 画布名称，并提供工作流面板开关与分享入口。
- 工作流、生成控制面板改为可折叠浮层，避免占满画布。
- 左侧素材库改为可开关浮动面板，画布保持全宽。
- 底部 LibTV 风格浮动工具栏：添加节点、工作流、素材库、剧本、整理、帮助、列表模式、缩放与适应视图。
- 工具按钮增加中文提示、键盘可访问名称和不小于 44px 的触控目标。
- 对齐、适应视图、缩放状态接入现有 Vue Flow 上下文，不新增后端接口。

- 空画布点击“适配画布”后仍显示 200%，符合当前没有节点可拟合的预期；缩小按钮可改变缩放状态。

- 本地前端代理到 `127.0.0.1:5679` 未启动，项目列表与集数 API 仍未验证；本轮未调用付费模型。

### 2026-07-15 集数上下文静态审计

- 选择具体集数时，画布图与素材库共用同一集数上下文，只保留该集分镜实际引用的角色、场景和道具。
- 切回“全部集数”时恢复项目级素材，并保留所有集的分镜节点与关系。
- 素材高亮在切换集数后会清除已不可见的资源，避免关系高亮指向当前上下文之外的节点。
- 新增 2 个纯函数测试覆盖当前集过滤、全部集回退和资源可见性判断。
- 分享入口现在优先调用系统分享；剪贴板不可用时会显示可手动复制的链接对话框，避免静默失败。
- 后端 `projectOwnership.test.js` 与 `dramaRoutes.test.js`：2/2 通过，确认公开模式下项目及静态工程文件按用户归属隔离。
