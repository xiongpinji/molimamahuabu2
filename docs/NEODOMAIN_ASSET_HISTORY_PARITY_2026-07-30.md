# Neodomain 资产库与生成历史对齐记录（2026-07-30）

## 目标与边界

- 目标页面：`https://xwow.neodomain.cn/workflow?sessionId=2076866643935690752`
- 目标能力：画布底部入口中的“我的资产”和“生成历史”。
- 实现范围：LocalMiniDrama 项目画布 `DramaCanvas.vue`。
- 数据原则：只使用本项目真实资产、图片生成、视频生成和画布节点数据；不引入演示数据，不改生成/计费后端。

## 实测结构

### 我的资产

- 以覆盖画布的大尺寸深色浮层展示，标题为“资产库”。
- 顶部一级分类：素材库、画布资产、图片工具（外部）、视频工具（外部）。
- 公共视图控制：平铺 / 日 / 周 / 月、缩略图尺寸、实时预览、批量选择、关闭。
- 素材库范围：全部画布；分类为全部分类、人物、场景、物品、风格、音效、其它、提示词；媒体类型为全部、图片、视频、音频、文本。
- 画布资产范围：当前画布、全部分组；类型为全部、图片、视频、音频、文本、3D World；卡片提供查看和定位。
- 图片工具与视频工具分别展示对应生成记录。
- 素材库为空时，展示“在画布节点右键保存到素材库”的三步引导。

### 生成历史

- 同样以覆盖画布的大尺寸深色浮层展示。
- 类型分类：全部、图片、视频、音频、3D World。
- 分组方式：平铺、日、周、月；当前时间组显示“本周 / 本月”等标签和数量。
- 工具：标签筛选与新建标签、卡片比例（1:1 / 4:3 / 3:4 / 16:9 / 21:9）、卡片尺寸（小 / 中 / 大）、网格/列表切换、批量选择、个人/协作/当前画布范围、关闭。
- 网格卡片显示缩略图和时间；列表卡片额外显示媒体类型；均可定位到画布节点。
- 详情区展示下载、查看原图、任务 ID、类型、生成时间、模型、生成方式、比例、节点、提示词复制和应用到画布。
- 批量选择区展示全选、已选数量、添加标签和打包下载。
- 空状态文案为“此画布暂无历史生成资产”。

## LocalMiniDrama 映射

- 素材库：`assetsAPI.list({ drama_id, include_global: 1 })`。
- 图片工具 / 图片历史：`imagesAPI.list({ drama_id })`。
- 视频工具 / 视频历史：`videosAPI.list({ drama_id })`。
- 画布资产、音频和文本：当前 `allGraphNodes` 中的 `canvasAsset` / `canvasMedia` 节点。
- 3D World：项目资产中 `type=model` 或模型文件扩展名。
- 节点定位：沿用 Vue Flow 现有节点定位能力；找不到节点时给出明确提示。
- 当前项目没有统一音频生成历史接口；音频历史只展示当前画布真实音频节点，不伪造记录。
- 标签在当前浏览器按项目持久化，用于筛选与批量归类；不新增后端表，不虚构跨设备同步。
- 协作范围当前没有后端会话接口；范围菜单保留真实可用的“当前画布 / 当前项目”，不虚构协作数据。

## 验收标准

1. 画布工具栏可独立打开“我的资产”和“生成历史”，两者互斥且可关闭。
2. 两个浮层的分类、分组、比例、尺寸、网格/列表、批量选择与详情交互可操作。
3. 素材、图片、视频和画布节点来自真实接口或当前画布状态。
4. “定位”能定位到对应画布节点；无节点关联时不误定位。
5. 前端定向测试、完整前端测试和生产构建通过。
6. 本地浏览器验证浮层布局、分类切换、空状态、详情与定位交互。
7. 部署只包含本次可审计提交，线上 `molimama.vip` 完成只读验收。
