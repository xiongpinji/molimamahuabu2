## 已确认缺陷与保护动作

1. `MiniMax H3` 的线上能力合同互相冲突：
   - 参考能力服务仍返回 `maxImageReferences = 4`；
   - 当前供应商客户端声明 `maxImages = 5`；
   - 公开目录因合并顺序同时暴露 `maxImageReferences = 4` 和 `maxReferences = 5`；
   - 本批次线上证据是 3 张成功、4 张失败。
2. 安全修复目标：统一锁定为 3 张，未采用素材不生成 `@图片N`，超限在积分冻结与供应商提交前失败。
3. 生产来源存在血缘分叉：线上相关源文件来自本地生产快照线，而 `origin/main@38135ad1` 仍是旧版 5 秒/480P 合同。直接从 `origin/main` 构建并覆盖会回退线上 15 秒/1440P 及后续视频能力。
4. 因此在修复代码前必须先选择并审计生产源码收敛方式；不能用旧 main 制作候选，也不能把线上文件无审计地反灌主干。
