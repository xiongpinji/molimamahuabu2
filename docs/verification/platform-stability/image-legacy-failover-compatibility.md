# 旧图片配置容灾兼容修复证据

## 触发原因

- 日期：2026-08-15
- 修复 PR：[#148](https://github.com/xiongpinji/molimamahuabu2/pull/148)
- 修复提交：`11b843cbc046ad32c32a557507819d01009e0bf9`
- 线上基线与候选使用同一套后端测试对比：当前线上有 62 个顶层既有失败，候选有 64 个；新增失败仅为普通用户音频目录兼容和旧图片配置同价回退。
- 图片回归可稳定复现：未配置 `logical_model_id` 的旧默认图片配置收到明确 `503 No available channel` 后，没有继续使用同价、启用且已验证的备用配置。

## 精准修复

- 新逻辑模型路由保持不变，继续记录供应商尝试、健康和未知任务状态。
- 只为未配置逻辑模型 ID 的旧图片配置恢复既有候选链。
- 候选链仍由现有规则限制为已启用、已验证且同价配置。
- 只有错误分类明确允许切换时才继续；策略拒绝、参数错误、已受理、结果未知和不可读产物仍禁止自动重提。
- 显式指定配置不进入旧配置自动回退。
