# 平台稳定性功能锁

本目录记录已完成“复现或验证—精准修复—回归—锁定”的共享稳定性合同。

- `locked_pass`：本轮验证无缺陷，未修改业务实现。
- `locked_fixed`：本轮复现缺陷并修复，要求清单中的测试持续通过。
- `blocked`：缺少外部条件或授权，不能宣称已验收。

触碰 `protectedPaths` 前必须在对应条目的 `unlock` 中填写原因、批准者和影响测试。CI 会读取目标分支已有清单；已锁定路径变化但未声明有效解锁时直接失败。

当前清单只覆盖图片、视频、文本共享供应商稳定性底座。画布、短剧工厂、剧本分析尚未在此阶段登记为通过；它们必须在后续独立阶段从真实入口逐项验证后才能锁定。
