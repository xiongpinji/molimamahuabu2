# 画布人像质感调节与本地图片拖入方案

## 固定边界

- 实现基线：交付时最新的 `origin/main`；提交前重新同步并复跑受影响测试。
- 只修改图片节点工具、画布图片拖放、对应真实图片处理服务和测试。
- 不修改 AI 音乐、短剧工厂、账户、计费规则或其他画布工具。
- 部署从线上当前发布目录复制隔离候选目录，只应用本次运行时代码补丁并校验；禁止本地整包覆盖、目录同步和线上 `git pull`。

## LibLib 登录画布学习结果

图片节点选中后，顶部一级入口为“人像质感调节 NEW”，悬停或点击后有两个子入口：

1. 人像调节：以当前图片为主参考，生成新的图片节点，不覆盖原图。
2. 情绪调节：识别人脸；识别不可用或没有命中时允许手动框选。用户从 5×5 情绪定位网格选择情绪，再生成新的图片节点。

情绪网格围绕“激动/平静”和“亲近/疏离”定位，共 25 个中文情绪。任务提交后保留源图、任务状态、失败回写和结果节点。

## 落地设计

### 人像处理链

- 新增 `portrait_texture` 与 `portrait_emotion` 两个图片工具操作。
- 仅在已审计的参考图图片模型声明人像能力，或已声明同一真实适配器的参考图创意能力时开放；未审计适配器绝不开放，也不返回模拟结果。
- 人像调节提交受控质感预设、1–5 强度和可选补充要求。
- 情绪调节提交 25 个受控情绪之一、1–5 强度和可选归一化人脸框。
- 有人脸框时，服务端从原图真实裁出脸部参考图，将“完整原图 + 脸部裁片”一起提交参考图模型；临时裁片在任务结束后删除。
- 输出必须保持源图比例与尺寸，通过图片解码、像素上限、结果非原图等校验后，才保存为派生素材并创建新节点。

### 本地图片拖入

- 首页自由画布 `/canvas/local` 与项目独立画布 `/canvas/:id` 使用同一图片文件筛选和节点规格函数。
- 支持一次拖入多张 PNG/JPEG/WebP/GIF/AVIF 图片。
- 每张图片立即用浏览器对象 URL 创建可预览节点；随后逐张上传。
- 上传成功后用稳定素材 URL 和素材 ID 替换本地预览；失败时保留当前预览并在节点写明错误。
- 多张图片按固定偏移排布，避免完全重叠。

## 验收标准

1. 图片节点一级入口和两个子入口可见，忙碌状态与后端能力门禁继续生效。
2. 人像调节真实调用参考图模型，生成同尺寸新素材和新图片节点，原图不变。
3. 情绪调节具备自动人脸识别、手动框选回退、25 情绪网格和真实双参考图请求。
4. 本地与项目画布拖入一张或多张本地图片后立即可预览，上传成功后可刷新恢复。
5. 无效文件不创建节点；上传或模型失败会写回可重试错误。
6. 前后端单测、画布端到端测试、生产构建通过；浏览器真实拖放与真实图片任务链通过。
7. Git 差异不包含 AI 音乐路径；SSH 部署只处理差异清单中的文件，并逐文件校验哈希。
