# 画布生成素材、情绪调节与弹层主题修复

日期：2026-07-31

## 修复范围

1. 图片或视频节点生成成功后，结果仍自动保存到项目素材库，但画布不再额外生成一张重复的“图片素材 / 视频素材”卡片。
2. 图片编辑框的“人像质感调节 → 情绪调节”必须把情绪名转换为眉眼、嘴角、面颊等可执行表情动作，并按 1–5 级强度要求模型产生可辨识变化。
3. 深色模式下，消息提示、通知、确认框、下拉框、气泡框和普通对话框等新弹层统一使用画布的深色主色调，不出现白色面板。

## 已确认根因

- 画布重建会把全部项目图片、视频、音频素材转换为 `canvasProjectAsset` 节点；节点生成结果自动入库后也进入了同一列表，因此产生重复卡片。
- 情绪参数和人脸裁片已经正确提交到后端，但提示词只包含抽象中文情绪名称和身份保持约束，没有明确面部动作，供应商模型容易保留原表情。
- Element Plus 的 Teleport 弹层没有完整的深色变量和全局深色表面规则，因而使用默认白色背景。

## 验收标准

- 自动入库的画布图片、视频生成结果不会被构建为 `canvasProjectAsset`；手动上传的项目素材仍正常显示。
- “浅然莞尔”等 25 个情绪预设都有明确的面部动作说明；提示词明确要求输出表情相对原图发生可辨识变化，并保留身份、构图与场景。
- 深色模式下常用 Teleport 弹层的背景、边框和文字颜色均来自现有主题变量；亮色模式行为保持不变。
- 前端定向测试、前端全量测试、前端生产构建、后端人像定向测试和后端全量测试全部通过。
- 真实页面验证无重复素材卡、情绪请求包含增强指令、弹层无白底后，更新现有 PR 并按生产保护流程上线复验。

## 精准修改边界

- 只修改画布项目素材过滤、后端人像情绪提示词、全局深色弹层主题及对应测试。
- 不删除自动入库数据，不改变素材库功能，不改动其他图片工具、生成供应商配置或亮色主题设计。
