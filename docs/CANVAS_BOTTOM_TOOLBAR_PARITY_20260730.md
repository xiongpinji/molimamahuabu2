# 独立画布底部工具栏交互补齐

## 目标

对齐参考画布可观察到的底部工具栏工作流，让入口不再只是装饰：

- 添加元素：打开现有文本、图片、视频、音频节点菜单。
- 我的资产：打开现有素材侧栏。
- 生成历史：展示当前画布运行队列，并可定位到对应节点。
- 节点定位：列出当前画布节点，并可直接聚焦。
- 画布设置：切换网格和缩略图。
- 自动吸附：控制 VueFlow 网格吸附。

## 验收标准

1. 六个入口均绑定真实画布状态或动作。
2. 非独立画布原有工具栏不回退。
3. 节点打组、整组执行、导演台与缩放入口保留。
4. 前端定向测试和生产构建通过。

## 本阶段不包含

- 不修改图片节点自身工具栏。
- 不复制参考站私有接口或实现源码。
- 不调整模型生成、计费或素材上传后端。
