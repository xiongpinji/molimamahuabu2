# 独立画布交互闭环（2026-07-28）

## 任务边界

本任务只处理独立画布及其共用节点编辑器的交互闭环：

- 节点选择与编辑器状态同步
- 画布缩放范围与缩放状态同步
- 连线删除、生成节点之间的合法连接
- 图片双击预览、节点编辑器全屏
- 右下角积分展示、遮挡与本次生成扣费提示
- 生成中进度、失败原因
- 参考图取消、`@` 图片候选与缩略图展示

## 明确排除

- 不修改会话 `019fa936-ca28-7fe3-9bc0-c17bc019a869` 正在开发的图片节点功能条。
- 暂停 MiniMax 音频模型接入。
- 不改动音乐站点及其部署目录。
- 不重构无关页面、组件或样式。

## 验收标准

1. 普通单击仅选中一个节点并打开对应编辑器；切换节点后编辑器内容同步更新。
2. 独立画布可通过现有缩放入口及 `Ctrl/Command + 滚轮` 放大至 800%，缩放百分比同步。
3. 选中连线后可以删除；合法的图片/视频生成节点可直接建立连接。
4. 图片结果可双击进入全屏预览；节点编辑器可进入和退出全屏。
5. 右下角展示当前积分且不遮挡编辑器；运行前显示预计扣费，运行中与完成后状态清晰。
6. 生成中显示进度状态；生成失败时节点和编辑器内均显示后端返回的失败原因。
7. 已挂载参考图可取消；输入 `@` 时显示可引用图片节点的缩略图与名称，并可插入引用。
8. 新增/更新的浏览器回归用例通过，前端生产构建通过。
9. 本地验证完成后才允许提交、推送、更新 PR 和部署。
