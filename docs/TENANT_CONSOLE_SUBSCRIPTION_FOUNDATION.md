# 租户控制台与订阅基础

## 目标

在已有租户隔离和租户积分账户之上，补齐公开收费平台可操作的租户入口，并建立后续接入真实支付所需的套餐、订阅和订单数据基础。

## 本阶段范围

1. 浏览器保存当前租户，所有登录请求自动携带 `X-Tenant-Id`。
2. 全局账户入口可切换租户，并在切换后刷新租户隔离的数据。
3. 租户控制台支持：
   - 创建工作区；
   - owner/admin 查看、添加和移除成员；
   - 查看当前租户积分与订阅状态；
   - 查看有效套餐；
   - owner/admin 创建待支付订单、查看和取消待支付订单。
4. 平台管理员可配置套餐名称、价格、月度积分、币种和状态。
5. 套餐、订阅、订单全部按租户隔离；重复提交相同 `client_order_key` 不产生重复订单。

## 明确不在本阶段

- 不伪造支付成功；
- 不激活付费订阅；
- 不自动发放套餐积分；
- 不接入微信、支付宝或其他支付渠道；
- 不开具发票。

这些操作必须在后续真实支付回调阶段完成，并以支付渠道签名、订单幂等和积分入账幂等为验收门槛。

## 验收标准

- [x] 未选择租户时沿用个人租户；选择后请求携带对应租户头。
- [x] 切换租户后项目、余额和订单随租户变化。
- [x] 普通成员不能管理成员或创建、取消订单。
- [x] 不同租户不能读取或取消彼此订单。
- [x] 相同租户和 `client_order_key` 重试只返回同一订单。
- [x] 创建订单后状态仅为 `pending`，不改变订阅与积分账户。
- [x] 后端全量测试、前端全量测试和生产构建通过。

## 验证记录

- 后端：租户与订阅订单定向测试、失效租户头恢复集成测试及全量测试通过。
- 前端：会话/租户请求头、套餐管理、余额失败状态定向测试及全量测试通过。
- 构建：Vite 生产构建通过；仅保留项目既有的大分块提示。
- 安全边界：订单测试确认保持 `pending`，订阅表和租户积分账户不因下单而变化。
