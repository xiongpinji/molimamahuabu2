# OpenVideo 导航板块拆分与茉莉妈妈映射

日期：2026-07-25
阶段：阶段一实施设计已锁定
参考站：<https://www.openvideo.top/>

## 1. 结论

OpenVideo 不是把所有功能堆在一个“项目页”里，而是用同一套账户、工作区、积分、模型和素材底座，拆成多个独立生产入口：

1. 工作台：快速生成与最近项目
2. 画布：纯画布项目中心
3. 工厂：剧本到成片的结构化流水线
4. 电商设计室：商品视觉垂直工作流
5. 插件：第三方模型接入与插件管理
6. 联系我们：支持与反馈

茉莉妈妈应采用相同的产品边界，但不复制其品牌、文案或私有实现。技术上使用同一个 Web 应用和同一个后端，不拆成不同 TCP 端口；通过一级导航、独立路由、项目类型和权限隔离完成拆分。

## 2. OpenVideo 各导航板块

### 2.1 工作台 `/`

页面职责：

- 顶部统一导航、工作区切换、余额、会员、主题、通知和账户入口
- 中央统一生成输入框
- 支持文字、图片、音频、视频等参考素材
- 选择生成类型、生成模式、模型、画幅、时长、清晰度和预计消耗
- 最近项目与新建项目入口

产品定位：跨项目、跨工具的统一入口，不承担完整项目编辑。

### 2.2 画布 `/canvas`

页面职责：

- 纯画布项目列表
- 个人项目与团队项目切换
- 搜索、筛选、网格/列表视图
- 文件夹管理
- 新建画布项目
- 进入项目后再打开节点画布

产品定位：自由探索型生产方式。画布项目独立存在，不依赖剧本、剧集或分镜结构。

### 2.3 工厂 `/factory`

页面职责：

- 剧本项目列表与搜索
- 新建剧本项目
- 从一句话灵感到完整成片
- 大纲、剧本、角色/场景/道具、分镜、图片、视频和批量生成

产品定位：结构化、可重复、适合短剧批量生产的流水线。

### 2.4 电商设计室 `/design`

一级页面内继续拆分为：

- 商品套图
- A+ 详情
- 服饰穿戴
- 爆款图复刻

商品套图页面包含：

- 商品原图上传
- 图片模型与规划模型选择
- 平台、国家、语言、比例配置
- 商品卖点与 AI 帮写
- 套图结构配置
- 生成历史

产品定位：复用底层图片模型、提示词、素材和历史任务，封装成电商专用工作流。

### 2.5 插件 `/plugins`

页面职责：

- 我的插件、插件广场、公司插件
- 上传 manifest JSON
- 可视化编辑 manifest
- AI 生成插件 manifest
- 图片、视频、文本模型模板
- 同步/异步生命周期
- 鉴权、接口路径、请求体模板、轮询、结果提取与下载配置

产品定位：把模型 API 接入标准化，避免每接一个模型都修改业务页面。

### 2.6 联系我们 `/contact`

页面职责：

- 微信与用户群
- 需求、Bug、功能建议和合作反馈
- 使用说明和响应预期

产品定位：公开收费平台的用户支持入口。

### 2.7 非一级导航公共能力

统一顶栏与账户菜单还承载：

- 个人/团队工作区切换
- 创建团队、申请加入团队
- 余额和会员/充值
- 个人中心、团队管理、通知、账户管理、修改密码
- 更新日志、使用教程、退出登录

会员页同时支持平台内置算力和用户自带 API 两种计费路径。

## 3. 茉莉妈妈当前能力映射

| OpenVideo 板块 | 茉莉妈妈当前入口 | 当前结论 |
| --- | --- | --- |
| 工作台 | `/` 项目列表、`/free-create` 自由创作 | 能力存在但分散，缺统一首页生成器和统一顶栏 |
| 画布项目中心 | `/canvas` | 当前直接进入单个本地画布，没有项目列表和服务端持久化；阶段一改为复用项目列表 |
| 完整画布编辑器 | `DramaCanvas.vue` | 已有节点、真实生成、素材库、工作流、运行队列与 3D 导演台；必须作为独立画布入口唯一实现 |
| 旧本地临时画布 | `HomeCanvas.vue` | 只作为兼容入口保留，不再作为主画布，也不继续扩展 |
| 工厂项目中心 | `/` 项目列表 | 已有项目列表，但与纯画布项目混合且没有“工厂”产品语义 |
| 工厂编辑器 | `/film/:id` | 已有完整短剧流水线，是最成熟的现有能力 |
| 工厂画布模式 | `/film/:id/canvas` | 已有项目画布、素材、分镜、批量生成、工作流和运行队列 |
| 电商设计室 | 无独立入口 | 有图片/视频生成、素材和模型底座；缺商品专用编排与四个垂直工具页 |
| 插件 | `/ai-config` | 有模型配置；缺 manifest 解释器、导入、插件广场和企业级分发 |
| 素材库 | `/media-library` | 已有图片/视频/音频筛选、上传、搜索和复用 |
| 工作区与积分 | `/tenant-console` | 已有多租户与积分基础 |
| 平台管理 | `/billing-admin`、`/account-admin` | 已有管理员计费、兑换码、账号和权限基础 |
| 联系我们 | 无 | 需要新增公开支持页 |

不能直接认定“功能完全一样”：

- 短剧工厂和项目画布的底层能力基本覆盖。
- 纯画布目前不是服务端项目，无法形成 OpenVideo 式项目中心。
- 电商设计室只有通用生成底座，没有完整垂直工作流。
- AI 配置不等于插件平台，manifest 运行时和插件分发仍是缺口。

## 4. 目标一级导航

建议最终导航：

1. `工作台`
2. `画布`
3. `短剧工厂`
4. `电商设计室`
5. `模型插件`
6. `联系我们`

右侧公共入口：

- 工作区
- 积分余额
- 兑换码
- 通知
- 账户
- 管理后台（仅有权限用户可见）

素材库不建议占用一级导航，放入工作区菜单，并在画布、工厂和设计室内统一调用。

## 6. 两种项目模式

新建项目时只做一次明确选择：

### 独立画布模式

- 产品入口不要求用户先走剧本流水线
- 技术上复用现有项目实体保存归属、租户、计费与画布状态
- 编辑器直接复用 `DramaCanvas.vue`，禁止复制、重写或另建简化画布引擎
- 节点、真实生成、素材、工作流和 3D 导演台与项目内画布保持同源
- 可直接调用文本、图片、视频、音频、角色、脚本和 3D 导演台能力
- 服务端保存多个画布项目
- 支持个人/团队归属与删除；搜索、文件夹和复制后续按真实需求补齐

### 流水线模式

- 延续现有短剧项目结构
- 剧本 → 角色/场景/道具 → 分镜 → 图片 → 视频 → 音频 → 导出
- 同一项目内部可以切换到项目画布
- 项目画布仍共享剧集、分镜和素材数据

建议项目分类字段：

```text
project_type = canvas | factory
```

独立画布项目不能继续只使用单一 `localStorage` 键。阶段一使用现有 `dramas` 项目实体并通过 `metadata.project_type = canvas` 分类，画布状态仍由现有画布保存接口持久化；只有当现有实体无法满足后续文件夹或版本能力时，才评估新增实体。

## 6.1 阶段一实现约束

- `/canvas`：画布项目中心，复用现有项目列表组件的画布模式。
- `/canvas/:id`：直接渲染与 `/film/:id/canvas` 相同的 `DramaCanvas.vue`。
- `/canvas/local`：保留原 `HomeCanvas.vue`，仅用于兼容旧本地数据。
- `/factory`：现有短剧项目中心；旧 `/` 暂时保留兼容。
- `project_type` 只承担入口分类，不分叉画布数据结构或生成链路。
- 不增加第二个前端端口，不复制 `DramaCanvas.vue`，不建立另一套节点注册表。

## 7. 实施顺序

### 阶段一：只重组现有能力

- 新增统一顶栏
- 首页改为“快速生成 + 最近项目”
- `/canvas` 改为纯画布项目中心
- `/factory` 承接现有短剧项目列表
- 旧 `/film/*` 路由兼容跳转
- 账户、工作区、积分和管理后台进入统一菜单

验收：导航边界清楚，现有生成链路不回归。

### 阶段二：独立画布项目体验完善

- 迁移本地画布为可选导入
- 在复用完整画布的前提下补搜索、文件夹、复制和版本
- 验证自动保存、恢复、个人/团队隔离
- 仅当现有项目实体确实无法承载版本/文件夹时再新增数据表

验收：不同账号、不同工作区和不同画布之间数据完全隔离。

### 阶段三：模型插件

- 把现有 AI 配置改造成模型中心
- 定义安全 manifest 规范
- 增加导入、校验、试运行、加密密钥和管理员审核
- 插件广场后置，不先开放未经审核的任意接口

验收：图片/视频模型通过统一解释器进入模型选择器，计费和失败写回一致。

### 阶段四：电商设计室

- 先用已有图片生成和素材接口完成商品套图
- 再增加 A+ 详情、服饰穿戴和爆款复刻
- 每个工具独立保留生成记录和素材回填

验收：不是静态 UI，每个工具至少有一条真实生成、资产入库和计费链路。

## 8. 首阶段不做

- 不拆多个 TCP 端口或多个前端部署
- 不复制 OpenVideo 的品牌、图标、文案和私有接口
- 不在导航改造时重写现有生成后端
- 不把尚未完成的电商工具或插件广场伪装成可用功能
- 不推送远端，先在本地完成和验收
