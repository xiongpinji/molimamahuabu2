# 画布 WASD / 方向键性能优化记录（2026-08-05）

## 目标与边界

- 优化项目画布 `/canvas/:id` 的 WASD 与方向键平移响应。
- 按下立即响应，持续按住时平滑、快速移动，不依赖操作系统不均匀的按键重复节奏。
- 输入框、文本域、下拉框和可编辑内容中的方向键行为保持不变。
- 不修改节点生成、积分、模型或后端业务逻辑。

## 修改前基线

- 生产画布 41 单次 `W` 只移动固定 `56px`：视口从 `translate(-502px, -1027px)` 变为 `translate(-502px, -971px)`。
- 持续移动完全依赖浏览器收到的重复 `keydown`，首次重复延迟和后续间隔由操作系统控制。
- 每次重复 `keydown` 都调用一次 `setViewport` 并重新启动布局保存防抖。
- 每次视口变化都会安排一次图虚拟化；节点数低于虚拟化阈值时仍复制并重新赋值完整节点、连线数组。

## 成功标准

1. 首次按下立即产生位移。
2. 按住期间使用 `requestAnimationFrame` 连续移动，目标速度不低于 `1400px/s`。
3. 重复 `keydown` 不创建额外动画循环或额外首步位移。
4. 松开全部平移键后停止动画，并只安排一次布局保存。
5. 少于虚拟化阈值时，单纯视口变化不再安排节点和连线虚拟化重算。
6. 单元测试、生产构建、真实浏览器按键验证、生产健康和日志检查全部通过后才交付。

## 最小修复

- WASD 与四个方向键统一映射，首按立即移动 `32px`。
- 按住后由单一 `requestAnimationFrame` 循环按时间计算位移，目标速度 `1400px/s`；对角移动归一化，避免斜向速度翻倍。
- 忽略同一物理按键的重复 `keydown`，避免叠加动画循环和首步位移；松开最后一个平移键或窗口失焦时停止，并只保留防抖后的布局保存。
- `input`、`textarea`、`select` 与可编辑内容继续使用原生按键行为。
- 当前节点数少于 `80` 时，视口变化只更新视口状态，不再调度整图虚拟化。

## 第二轮优化（用户反馈仍慢且卡顿）

### 实测基线与根因

- 在 64 节点画布持续按住 `W` 约 `1.45s`：P95 帧间隔 `33.4ms`、P99/最大 `66.6ms`，`21` 帧超过 `25ms`。
- 逐帧节点 DOM 变更为 `0`，排除节点虚拟化重建；卡顿集中在每帧调用 Vue Flow `setViewport` 触发 D3 与 Vue 响应式状态链。
- 同一画布直接更新变换层的 GPU 合成属性后：P95/P99 `16.7/16.8ms`，超过 `25ms` 和 `50ms` 的帧均为 `0`。这证明合成层路径可消除当前热路径造成的掉帧。

### 第二轮成功标准

1. 首步位移提升至 `56px`，持续速度目标提升至 `2200px/s`。
2. 按住期间由浏览器原生合成线程线性更新 `.vue-flow__transformationpane` 的 `translate3d`；主线程不运行逐帧业务代码、不调用 `setViewport`、不写 Vue 响应式视口。
3. 松开最后一个方向键时，只调用一次 `setViewport` 同步最终视口并安排一次持久化。
4. 64 节点压力用例不产生长任务、节点 DOM 变更或逐帧 style 写入；运动期间 style 属性变更不超过 `3` 次，超过 `50ms` 的主线程采样帧为 `0`。
