# 独立画布自由节点阶段 4

日期：2026-07-25

## 目标

独立画布入口 `/canvas/:id` 只依赖项目名称，不再要求先创建或选择剧集。用户可以在空白画布中通过右键菜单或底部“添加”按钮创建文本、图片、视频、音频节点。

选择节点类型后必须先打开对应的小型配置窗口，填写标题和内容／提示词后再落到画布；不能把“图片”“视频”“音频”直接解释成选择本地文件。显式“上传”与“素材库”入口继续保留。

## 范围与取舍

- 继续复用现有项目记录和 `canvas_layout` 元数据作为存储容器，不新增一套项目表。
- 独立画布不自动创建剧集，也不显示剧集、角色、场景、道具和分镜流水线骨架。
- 流水线画布 `/film/:id/canvas` 的剧集与分镜工作流保持原样。
- 自由节点支持文本、图片、视频、音频四类；节点保存标题、内容／提示词和可选媒体地址。
- 本阶段完成节点创建、编辑、移动、连线、删除后的保存／恢复闭环；真实模型运行继续复用后续节点配置与生成链路阶段。

## 验收标准

1. 在画布项目中心只输入项目名称即可创建并进入独立画布。
2. 没有任何剧集时，独立画布仍可右键并显示文本、图片、视频、音频节点入口。
3. 点击图片、视频或音频入口不会打开系统文件选择器，而是打开对应节点配置窗口。
4. 显式“上传”仍可选择本地文件并形成项目素材节点。
5. 新增自由节点刷新页面后仍存在；移动、编辑、删除和手动连线结果可恢复。
6. 原流水线画布的剧集／分镜创建和上传行为不发生回归。
7. 聚焦测试、前端全量测试与生产构建通过，并完成浏览器回归。
