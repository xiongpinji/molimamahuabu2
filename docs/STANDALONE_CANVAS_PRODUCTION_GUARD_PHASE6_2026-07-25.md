# 独立自由画布生产闭环 Phase 6（2026-07-25）

## 目标

在不重写现有图片、视频生成系统的前提下，补齐独立自由画布进入公开收费平台所必需的音频计费、资源归属和素材隔离，并建立可重复、零真实费用的供应商协议证据。

## 当前事实

- 图片、视频自由节点已经复用现有生成任务、模型配置、积分预扣与结算框架。
- 当前运行库没有 `ai_service_configs`、`model_credit_prices`、`tenant_credit_accounts` 数据，不能执行真实付费供应商验收。
- 音频自由节点当前使用同步 `/audio/extract`，尚未携带项目归属，也没有积分预扣、成功结算和失败退款。
- 音频当前保存到非项目目录；公开平台静态资源中间件可能拒绝回读。
- 素材列表允许未指定项目的裸查询，公开平台模式存在跨项目或跨租户暴露风险。
- Phase 5 浏览器测试使用本地路由测试桩，只证明前端协议与状态回写，不能替代真实供应商证据。

## 范围与约束

- 仅修改完成生产闭环所必需的路径，不重构图片、视频生成系统。
- 保持音频同步接口，先补项目归属、计费、项目目录和失败退款；本阶段不扩展为异步任务。
- 公开平台模式必须拒绝无法确认归属的素材查询和静态资源访问。
- 本地 provider shim 只用于验证真实 HTTP 协议、状态机、产物、隔离和计费逻辑，不得宣称为线上供应商实测。
- 真实供应商调用必须在有效配置、模型价格、租户余额齐备后单独执行，并保存脱敏证据。
- 不提交 `frontweb/.codex-dev/` 等本地运行日志。

## 任务拆分

### Task 1：音频生产闭环

- 自由音频节点请求携带当前项目 `drama_id`。
- `/audio/extract` 在公开平台模式校验项目归属。
- TTS 输出保存到可授权回读的项目目录。
- 按实际 TTS 模型执行积分预扣、成功确认、失败退款和审计记录。
- 覆盖成功、余额不足、供应商失败退款、跨租户访问和静态文件回读。

### Task 2：素材库隔离

- 公开平台模式禁止无项目范围的素材裸查询。
- 素材列表、详情、创建和删除均验证项目归属。
- 独立画布生成素材保留 `storyboard_id=null`，但必须绑定当前项目。
- 素材入库名称使用节点标题或结果文件名，避免“未命名”记录。
- 覆盖同租户回读与跨租户拒绝。

### Task 3：供应商协议证据

- 图片：本地 OpenAI 兼容 provider 返回真实 PNG 字节，验证任务、生成记录、本地文件和失败退款。
- 视频：本地异步 provider 返回任务 ID，验证轮询恢复、产物回读和失败写回。
- 音频：本地 OpenAI TTS 兼容 provider 返回真实音频字节，验证项目目录、素材回读和计费。
- 保留环境变量控制的 live smoke 入口；未配置时明确跳过并记录 `blocked`。

### Task 4：回归与审计

- 前后端定向测试、全量测试和生产构建通过。
- 浏览器验证独立画布音频运行、素材入库和素材库筛选。
- 审计 Git 变更，只选择性提交本阶段文件。
- 文档分别记录 `implemented`、`local_provider_verified`、`live_provider_verified`、`blocked`。

## 验收标准

1. 独立音频节点无需剧集或分镜，但必须绑定当前项目。
2. 公开收费模式下，音频生成成功只扣一次积分；供应商失败或产物不可用必须退款。
3. 音频静态 URL 可由项目所有者读取，其他租户不可读取。
4. 素材库不会因省略 `drama_id` 返回其他项目或租户素材。
5. 图片、视频、音频本地 provider shim 均产生可读取的真实媒体字节和可核对的数据库记录。
6. 未配置真实供应商密钥、价格或余额时，live smoke 明确为 `blocked`，不伪造通过结果。
