# 画布节点编辑框完整适配修复

## 用户验收基准

参考图 1 是唯一目标展示方式：

- 编辑框的标题、参考图区域、提示词、参数区和底部操作按钮一次完整显示。
- 编辑框根容器不出现纵向或横向滚动条。
- 空间不足时缩放整个编辑框，不能只缩外框后裁切内部内容。
- 编辑框继续锚定当前节点；节点移动、画布缩放或平移时同步更新。
- 图片、视频、音频、文本节点以及不同节点宽度都遵守同一规则。
- 编辑框始终完整保持在浏览器视口内。

参考图 2 的以下行为必须被回归测试拦截：

- 根编辑框使用 `max-height` 截断内容。
- 根编辑框使用 `overflow-y: auto` 或横向滚动条补救截断。
- 参数区或底部按钮落到视口外，需要滚动才能操作。

## 实现边界

- 只修改节点编辑框的尺寸计算、定位样式与对应 E2E 测试。
- 不修改节点生成、计费、素材、提示词引用或后端逻辑。
- 生产部署只操作 `/opt/moli-drama` 与 `moli-drama.service`。
- `/opt/moli-mama`、端口 8787 和 AI 音乐 PM2 进程是禁止修改范围。

## 验证门

1. 现有实现必须被“根编辑框无横纵溢出”用例稳定判红。
2. 20% 与 100% 画布缩放下，编辑框完整位于视口。
3. 不同节点宽度和类型下，根编辑框 `scrollHeight <= clientHeight`、`scrollWidth <= clientWidth`。
4. 底部操作区位于编辑框可视边界内。
5. 原有节点拖动、画布缩放、画布平移和全屏编辑回归继续通过。
6. 完整画布 E2E 与生产构建通过后才允许部署。
