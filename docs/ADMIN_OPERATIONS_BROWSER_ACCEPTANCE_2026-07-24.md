# 管理运营闭环浏览器验收（2026-07-24）

## 验收范围

在隔离测试数据库和本地公开平台模式下，对 `/billing-admin` 进行真实浏览器验收。测试账号、
JWT、管理员令牌和数据库均为本机临时数据，本文不保存任何凭据，也未执行积分调整、退款、
兑换码签发或账号状态变更。

## 浏览器结果

- 匿名访问 `/billing-admin` 会跳转登录页，页面无权限数据泄露。
- 管理员登录后，可通过独立管理员令牌解锁后台。
- “模型计费”“兑换码”“账号管理”“积分流水”“积分对账”五个页签均可进入并正常读取。
- 稳定后端进程下，账号、租户、积分流水和对账初始化请求均返回 HTTP 200。
- 页面未出现错误提示；未在验收过程中执行任何写操作。

## 自动化回归

- 前端后台路由门禁：匿名跳转登录、非管理员跳转项目列表、管理员允许访问。
- 本地单用户兼容：无 Bearer 读取平台账号成功，角色修改和兑换码签发不会因缺少
  `req.user` 崩溃。
- 平台 RBAC：角色矩阵、暂停/恢复、强制退出、旧 JWT 失效和最后管理员保护。
- 兑换码：批量签发、租户绑定、到期/停用、并发与跨租户隔离。
- 积分对账：陈旧预扣扫描、安全退款、幂等冲突、租户隔离和管理员审计归属。

## 交付门槛

浏览器验收只证明本地隔离环境的页面与 API 闭环。正式公开环境仍必须按
`PUBLIC_PLATFORM_SETUP.md` 配置 HTTPS、密钥、首个管理员、数据库备份、告警和真实供应商
小额计费核对；本阶段不包含支付渠道。
