# 导航栏固定比例与 Ctrl 滚轮缩放保护

## 问题

当鼠标位于顶部导航、弹窗或非画布页面时，`Ctrl/Command + 鼠标滚轮`可能触发浏览器整页缩放，导致首页、画布和企业页面的导航栏比例一起变化。

## 实现边界

- 在应用入口以捕获阶段监听 `wheel`，覆盖导航、弹窗和普通页面。
- 仅在 `ctrlKey` 或 `metaKey` 为真时阻止浏览器默认缩放。
- 不停止事件传播，保留 `HomeCanvas`、`DramaCanvas` 现有画布缩放处理。
- 不改变浏览器菜单缩放、`Ctrl + +/-`、普通滚轮滚动或页面响应式布局。

## 成功标准

1. 首页导航、画布导航和企业页面导航上的修饰键滚轮事件均被取消默认行为。
2. 普通滚轮不被全局保护器拦截。
3. 画布收到修饰键滚轮后仍改变 Vue Flow 视口缩放值。
4. 专项测试、完整前端测试和生产构建不引入新失败。
