# 节点生成进度动画任务

## 目标

- 所有画布节点在生成期间显示旋转加载动画。
- 自由画布节点在接口提供真实进度时显示真实百分比和进度条；接口尚未提供进度时只显示不定进度动画，不伪造百分比。
- 编辑框右下角运行按钮在生成期间只显示旋转图标，移除“生成中”文字。

## 修改边界

- 仅修改节点生成状态的展示、自由节点任务轮询中的真实进度回写，以及对应测试。
- 不修改节点生成参数、模型调用、计费、画布布局或其他业务交互。
- 生产发布从实时 `/opt/moli-drama/current` 制作候选，只叠加本次提交差异；禁止用本地工作树整体覆盖生产。
- 候选必须保留 `canvas-credit-callout-v1`，并通过共享 release guard、CAS、备份、活动任务、健康、日志和 AI 音乐进程隔离检查后才能切换。

## 验收标准

1. 自由画布的文本、图片、视频、音频节点在运行中都显示旋转动画。
2. 有真实任务进度时，节点和编辑框显示同一真实百分比；无真实进度时显示循环进度动画且不显示 `0%`。
3. 编辑框右下角不再出现“生成中”三个字，只显示旋转动画并保持禁用状态。
4. 项目画布节点状态覆盖层同样遵循“有真实百分比则确定进度、否则不定进度”的规则。
5. 前端定向测试、完整测试、构建和浏览器验证通过。
6. 生产候选只包含本次修改，受保护积分提示合同和并行会话线上改动未被覆盖。
