# 剧本分析重启修复原子发布

## 故障证据

- 线上 `server.js` 和 `routes/scriptAnalysis.js` 已调用在途任务接口。
- 同一线上发布中的 `services/taskService.js` 未实现这些接口，形成文件级不一致。
- 最新主分支同样缺少完整的在途任务、遗留项目收敛和前端网关错误重试实现。

## 修复范围

1. 剧本分析后台任务登记为进程内在途工作，服务关闭时在有限时间内等待完成。
2. 启动清理遗留任务时，把没有活动任务的 `analyzing` 项目收敛为 `failed`。
3. 前端轮询有限重试 502/503/504 与网络中断，并过滤 HTML 网关错误页。
4. 从切换时最新 `/opt/moli-drama/current` 派生候选发布，只覆盖实际不同文件。

## 禁止范围

- 不启动付费剧本、图片或视频生成。
- 不修改生产数据库、积分、模型密钥、Nginx、PM2 或 `/opt/moli-mama`。
- 不整体上传本地仓库，不覆盖其他会话已经上线的文件。

## 验收标准

1. 回归测试证明在途任务可等待且有超时上限。
2. 回归测试证明遗留剧本分析项目状态可收敛，原剧本与成功版本不变。
3. 回归测试证明网关 HTML 不会作为用户提示，短暂故障可有限重试。
4. 后端全量测试通过；前端全量测试相对 `origin/main` 不新增失败；生产构建通过。
5. 发布前再次确认线上父版本未变化；若变化则重新派生候选发布。
6. 发布后 `moli-drama.service`、5679、公开健康接口正常，AI 音乐 8787 的进程号保持不变。
7. 发布清单记录父版本、修改文件、哈希、回滚目录和验证结果。
