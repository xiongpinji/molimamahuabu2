# 共享 Skill 中心与短剧工厂导入预览计划

## 目标

在不改变现有剧本分析、画布和短剧工厂执行能力的前提下，把当前导演 Skill 收敛到共享注册表，并让审核通过的生产包可以先预览其进入短剧工厂时的上下文、数量和来源。

## 边界

1. 剧本分析现有 Skill 列表、选择、执行、快照和生产包输出保持兼容。
2. 画布继续只消费已经审核并导入的 Skill 快照和视觉方案，不增加自动生成或自动改写。
3. 短剧工厂本阶段只提供导入预览和明确的前往入口，不创建项目、不写数据库、不调用模型、不扣积分。
4. 原剧本、锁定事实、图片提示词和视频提示词保持原值；预览只读取和克隆。
5. 注册表必须如实区分三种能力：剧本分析可执行、画布可消费、短剧工厂仅预览；不得把未实现能力标记为可执行。

## 数据契约

- 共享 Skill 注册项保留名称、版本、来源、许可归属、支持模块、输入/输出契约、权限以及计费/超时/重试/退款策略的继承边界。
- 现有 `scriptAnalysisSkillRegistry` 保持兼容入口，内部委托共享注册表。
- 前端模块适配器输出只读的短剧工厂预览：项目标题、梗概、类型、锁定事实、角色/场景/道具/集/镜头数量、Skill 快照、视觉方案和来源版本。
- 仅当前审核通过版本允许打开短剧工厂预览；历史版本和未通过版本继续禁用。

## 验收标准

1. 现有剧本分析 Skill 注册表测试与接口测试不回归。
2. 共享注册表准确返回 `execute / consume / preview` 三种模块能力。
3. 工厂预览不修改传入生产包，保留锁定事实和全部提示词。
4. 剧本分析页面出现“预览导入短剧工厂”，预览中显示来源、Skill 和生产数量，并明确不自动写入。
5. 点击“前往短剧工厂”只导航到 `/factory`，不调用创建项目、生成或计费接口。
6. 定向测试、全量相关测试、生产构建和真实浏览器只读验收通过后，才允许增量部署。
