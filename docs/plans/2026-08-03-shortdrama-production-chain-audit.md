# 短剧工厂真实生产链审计计划

## 目标

在不调用图片、视频或合成模型、不消耗积分、不改变项目 45 生产数据的前提下，确认“已审核剧本导入短剧工厂”之后的真实生产链是否具备可安全执行单镜生产的条件。

## 当前基线

1. 项目 45 / 第 28 集已完成来源追溯、锁定事实展示和生成前零扣费预检。
2. 当前预检显示视频模型、画幅、分镜内容、提示词、人物/场景关系和镜头时长均已就绪；缺失参考图作为非阻断警告。
3. 本阶段不把前端按钮存在、静态测试或历史任务当作真实生产闭环证据。

## 审计范围

1. 前端请求：单镜图片、单镜视频、批量生成和成片合成的请求参数与任务轮询。
2. 后端任务：任务创建、资源归属、重复提交保护、状态持久化、启动恢复和取消语义。
3. 账务：预扣、成功结算、失败退款、超时/未知状态处理和重复回调幂等。
4. 产物：图片、视频和最终成片 URL 是否写回正确的项目、集和分镜，刷新后能否回读。
5. 线上只读证据：当前发布目录、可用模型配置、项目关系和历史任务状态；不提交生成请求。

## 非目标

1. 未经用户确认，不进行任何付费生成或积分变动。
2. 不修改剧本分析来源文本、锁定事实、项目 45 的角色/场景/道具/分镜数据。
3. 不触碰 AI 音乐程序、8787 端口、Nginx、密钥或共享数据库内容。
4. 不整体上传本地项目，不覆盖并行会话的发布结果。

## 验收标准

1. 输出从前端按钮到后端路由、任务、账务和产物落库的逐段证据，并明确每段状态：已实现、测试覆盖、线上只读验证或缺口。
2. 若发现缺口，先写能够稳定复现的失败测试，再做最小修复；不得顺手重构相邻代码。
3. 定向测试、相关回归和生产构建通过后，才能进入部署。
4. 部署必须从切换时最新 `/opt/moli-drama/current` 派生，只替换本阶段修改文件并保留并行发布。
5. 无扣费线上验收完成后，再向用户申请一次单镜真实生成授权，并明确预计积分消耗和所用模型。
