# 画布节点编辑框跟随与视口约束

## 用户目标

- 节点被选中后，编辑框稳定锚定节点并随节点、画布缩放和平移移动。
- 编辑框不进入 Vue Flow 缩放层，不随画布比例变得难以操作。
- 编辑框始终完整留在浏览器视口内，不撑大根页面，也不制造横向或纵向页面滚动条。

## 当前证据

- 参考视频时长 17.24 秒，展示独立浮层式编辑框；浮层尺寸稳定并位于所选节点下方。
- 当前视频时长 3.07 秒，展示项目画布的图片节点与节点工具栏，但没有足够清晰的单帧证据证明编辑框的最终布局状态。
- 线上 `/canvas/48` 当前静态包包含固定定位编辑框逻辑，因此不能仅凭视频假定线上缺少该实现。

## 验收信号

使用项目画布 `/canvas/3` 的 Playwright 回归作为反馈环：

1. 选中自由图片节点后，编辑框挂载到 `document.body` 且为 `position: fixed`。
2. 编辑框边界始终在浏览器视口内，根文档尺寸不超过可视尺寸。
3. 拖动节点、缩放和平移画布后，有可操作空间时编辑框与节点保持 12px 的下方锚定间距。
4. 编辑框自身内容完整，无内部横向或纵向滚动条。
5. 节点贴住或超出视口底边时，编辑框按下方、侧边、上方的顺序选择能保持可操作尺寸的位置；不覆盖节点，也不平移整张画布。

若当前代码无法稳定复现失败，只交付诊断结论和测试覆盖，不在没有红色证据时盲改布局。

## 诊断与结果

- 最小复现证明：点击靠近视口底部的项目自由节点后，画布从 `translateY(0)` 自动跳到 `translateY(-203px)`。
- 根因是编辑框下方空间不足时调用 `panCanvasForNodeEditor`，主动平移整张 Vue Flow 画布后提前结束本帧定位。
- 修复后不再移动画布；下方空间足够时编辑框整体等比缩放并继续固定在节点下方。
- 图片节点以节点、工具栏、菜单和历史面板的可见联合矩形作为避让边界；打开工具菜单时沿用现有交互暂停编辑框，避免两套操作层互相遮挡。
- 边界降级规则：若下方空间不足以保持至少 30% 的可操作尺寸，则编辑框优先停靠到节点左右空闲更多的一侧；两侧也不足时，使用节点上方的实际空隙并保持 12px 间距。若四周都无法容纳 30% 尺寸，则暂时隐藏编辑框，节点回到可用区域后自动恢复。该规则不覆盖节点、不改变画布 transform，也不会把根页面撑大。
- 官方画布 E2E：48 通过、1 跳过、0 失败。
- 前端生产构建通过；Node 自动发现的全量测试为 518/524，通过数和 6 个既有失败与修复前基线一致。
