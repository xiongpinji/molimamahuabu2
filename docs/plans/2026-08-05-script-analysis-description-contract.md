# 剧本分析描述合同修复

## 线上故障证据

- 2026-08-05 只读检查生产数据库，最新两个分析包均为 `schema_version=1.0`。
- 人物、场景、道具和分镜没有统一的非空 `description` 合同；内容分散在
  `appearance`、`visual_design`、`environment`、`story_function`、
  `image_prompt` 和 `video_prompt` 等不同字段。
- 当前页面只读取少数回退字段，因此已有内容仍可能显示“暂无描述”。

## 修改范围

1. 输出提示词为人物、场景、道具和每个镜头声明可读 `description` 字段。
2. 校验上述四类对象至少有可读描述来源；归一化时统一写入 `description`。
3. 页面兼容旧分析包的已有字段，保证对象和数组被转换为可读文本。

## 不在范围

- 不修改历史分析包、原剧本、审核状态、版本、积分或模型配置。
- 不合并或部署尚未完成真实模型验收的导演故事板 V2。
- 不自动重新运行用户的分析任务，避免未经确认产生模型费用。

## 验收标准

1. 失败测试能复现四类描述缺失，并在修复后通过。
2. 新生产包归一化后，人物、场景、道具和镜头均有非空 `description`。
3. 旧生产包使用现有替代字段时，页面不再显示“暂无描述”或
   `[object Object]`。
4. 后端定向/全量测试、前端定向/全量测试和生产构建通过；既有失败单独披露。
5. 如需发布，候选必须从实时 `/opt/moli-drama/current` 克隆，保留
   `canvas-credit-callout-v1`，通过共享 release guard 后才能切换。
