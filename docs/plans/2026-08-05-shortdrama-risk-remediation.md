### iCreat HTTP 400 证据边界

- 已成功样本首帧为 JPEG `2048x1152`（16:9），请求比例 16:9、480p、4 秒。
- 4 个供应商内部 HTTP 400 使用的实际文件均为同一 JPEG `1280x1707`（约 3:4），请求比例 16:9、720p、15 秒；文件格式、尺寸和大小满足公开协议。
- 官方协议支持显式比例及 `adaptive`，但未声明输入首帧与输出比例不一致必然失败。因此当前只能确认强相关差异，不能把比例不一致写成已证实根因，也不在本次修复中擅自改变用户选择的输出比例。
