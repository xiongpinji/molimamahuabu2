# 恢复完整画布主入口

## 问题

首页新增的独立自由画布 `/canvas` 不携带项目 ID，只保存基础节点状态；它被放到项目列表的全局头部和“快速开始”区域后，用户会误以为原有完整画布功能被删除。

原完整画布仍位于 `/film/:id/canvas`，以项目数据为真源，包含剧本、分镜、素材、生成参数和工作流能力。

## 恢复边界

- 项目列表只把项目卡片中的“打开画布”作为主要画布入口。
- 普通页面的全局头部不再提供直达独立自由画布的主入口。
- 主要入口必须携带项目 ID，并进入 `/film/:id/canvas`。
- 保留 `/canvas` 和 `HomeCanvas.vue`，不删除用户可能已有的本地自由画布数据。
- 不修改生成服务、计费逻辑或项目数据结构。

## 验收标准

- 项目列表不再显示“首页自由画布”主入口。
- 制作、详情、配置和素材等普通页面不再显示全局“首页画布”入口。
- 项目卡片“打开画布”进入 `/film/:id/canvas`。
- 完整画布能加载项目，并显示生成参数、工作流及现有节点面板。
- 前端 Node 测试、生产构建和浏览器冒烟验证通过。
