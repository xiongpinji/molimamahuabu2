# 画布稳定性第三阶段

## 范围

本阶段只处理用户已确认的八项问题：

1. 图片和视频预览可可靠退出。
2. 图片节点拖动不因持久化或生成状态更新卡顿。
3. 多人同时使用画布时避免高频全量保存。
4. 充值与积分记录展示操作后的剩余积分。
5. 连线目标节点提供直接生成入口。
6. 生成失败展示服务端返回的具体原因。
7. 本地图片可直接拖入画布形成图片节点。
8. 图片生成完成后结果只提交一次，不反复切换预览。

## 约束

- 同时覆盖 `/canvas/local` 与 `/canvas/:id` 的实际实现层。
- 不改动音乐业务、支付能力或模型供应商配置。
- 不在拖动过程中同步完整节点媒体数据；拖动停止后再保存。
- 生成失败不进行隐式重试，避免重复扣费。

## 验收

- Escape、遮罩和关闭按钮均可退出图片/视频预览。
- 连续拖动含生成结果的图片节点时，不触发逐帧全量序列化。
- 普通节点点击保持单选；连线中点可执行目标生成。
- 拖入 PNG/JPG/WebP 后在落点创建图片节点。
- 失败节点显示后端原始错误摘要。
- 积分记录每条包含“剩余积分”或明确的历史缺失标记。
- 同一任务完成回调只更新一次最终结果。
- 前端定向测试、构建和浏览器回归通过后才提交部署。
