# 画布节点可见性热修

## 目标

修复独立画布中新建或刷新后可见的节点，在点击画布空白处后变为隐藏的问题。

## 修改范围

- `frontweb/src/views/DramaCanvas.vue`
- `frontweb/e2e/standalone-canvas-runtime.spec.js`

不修改后端、数据库、生成任务、积分、素材文件或 AI 音乐服务。

## 成功标准

- 新建图片节点立即可见。
- 点击画布空白处后节点仍可见。
- 节点继续保存到 `canvasLayout.free_nodes`。
- 最新主线的完整前端测试不新增失败。
- 生产构建、预检、健康检查与只读线上浏览器验收通过。

## 本地证据

- 最新 `origin/main`（`71f60fd`）仅加入回归测试时稳定失败：节点 DOM 存在但为 `hidden`。
- 应用修复后精确 E2E 连续 3 次通过。
- 完整前端测试：热修与干净主线均为 504 项、498 通过、相同 6 个既有失败。
- 独立画布 E2E：热修 8/10；干净主线 6/9。两边相同的 2 个既有失败与本问题无关，热修额外通过新增回归和原有新建节点场景。
- 生产构建通过，1820 个模块完成转换。

## 发布门禁

- 从实时 `/opt/moli-drama/current` 克隆候选 release。
- 仅覆盖 `frontweb/src/views/DramaCanvas.vue`，测试与本文档不进入运行目录覆盖清单。
- 切换前必须确认部署锁、CAS、磁盘、数据库备份、活动任务/预扣为空和 AI 音乐 PID 不变。
- 原子切换后验证内部与公网健康、`/canvas/local`、构建资源、错误日志和回滚目标。
