# 剧本分析故事板导演 V2

## 目标

把故事板方法、男频/女频/融合编剧策略、微表情与肢体表演、AI 视频导演和提示词编译整合进现有“剧本分析”。剧本分析负责生成、展示、校订和审核完整导演故事板；审核通过后才允许追加进入现有画布执行图片与视频生产。

## 已确认产品路径

`剧本分析 → 导演故事板 → 人工审核 → 追加进入画布`

- 剧本分析是本能力的主入口和策划成品页。
- 导演故事板是剧本分析结果的核心阶段，不是独立产品。
- 画布负责审核后的节点编排、3D 预演、图片和视频执行。
- 短剧工厂不属于本任务主流程；既有兼容接口可以保留，但不得成为新界面的主要动作。

## 核心行为

1. 用户选择男频、女频、融合或自定义策略；默认融合，策略只提供创作启发，不把性别套路作为硬校验。
2. 分析生产包保持原剧本、锁定事实、镜头来源依据和不可变版本链。
3. 每个镜头除现有图片/视频提示词外，还包含结构化表演轨和模型无关提示词结构。
4. 表演轨描述角色的初始状态、触发事件、分段微表情/呼吸/声音/肢体变化和最终状态。
5. 提示词编译根据目标模型能力生成最终提示词、负面约束、评分和降级警告；Seedance 2 是首个专用适配器，但不是内核硬依赖。
6. 剧本分析页面直接展示可校订的导演故事板；只有当前审核通过版本可以追加进入画布，且不得覆盖画布已有节点。

## 验收标准

- Skill 清单可安全返回 V2 元数据，不暴露系统提示词或本地资料路径。
- 四种策略均可生成合法生产包，默认值为融合。
- 非法表演时序、缺失来源依据或无效提示词结构会在保存版本前被拒绝。
- 页面可查看故事结构、人物场景、导演故事板和生产检查。
- 同一审核版本重复进入画布保持幂等，不覆盖已有节点；未审核版本不得进入画布。
- 后端定向与全量测试、前端定向测试和生产构建全部通过。
