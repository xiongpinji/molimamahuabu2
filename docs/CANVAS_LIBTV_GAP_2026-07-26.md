# 独立画布与 LibTV 差距清单（2026-07-26）

## 范围与基线

- 对比对象：登录态 LibTV 画布、`/canvas/local`、`/canvas/:id`。
- 实现基线：短剧工厂现有 `DramaCanvas` 内核；独立项目画布继续复用同一套节点、素材、模型、任务和结果持久化能力。
- `/canvas/local` 定位：不绑定项目的浏览器本地草稿，不伪造模型调用、项目素材库或运行结果入库。
- 禁止修改：`AccountAdmin`、`TenantConsole`、`BillingAdmin`、`AdminWorkspace*`。
- 本轮不调用 LibTV 付费生成，不复制其私有接口；登录态页面仅用于交互和能力核对。

## 登录态核对证据

LibTV 当前画布可见能力：

- 无限画布、节点拖动、滚轮/快捷键缩放和平移、适配画布、缩略图、网格与连线显隐；
- 空白处添加节点、素材库、角色库、历史、快捷键和教程入口；
- 图片等媒体节点、工作流/分镜切换、3D 导演台节点；
- Agent 输入入口；
- 同一画布在其他标签打开时的编辑锁提示。

核对限制：公开副本处于“正在跟随”状态，个人画布出现多标签编辑锁，因此未执行会改变内容或产生费用的节点运行；能力判断以登录态可见控件、节点内容和本仓库真实调用链为依据。

补充截图复核：LibTV 的图片、视频、文本和音频节点采用“画布上的紧凑预览节点 + 选中后展开节点专属编辑器”的交互；图片连接到视频后，视频编辑器会立即列出已采用的参考图。仅存在连线、但不展示采用关系，不能视为交互对齐。

## 本轮完成状态

- `/canvas/:id` 四类自由节点均使用固定在视口底部的专属编辑器，支持全屏、关闭和 `Esc` 退回。
- 图片、视频、文本和音频的核心参数均在节点编辑器内直接可见，不再依赖无实际内容的配置按钮。
- 图片连入视频后，视频编辑器立即展示来源卡片；同一来源集合直接进入真实视频请求。
- 文本生成和中英翻译走真实 AI 路由；图片/视频支持 1–4 个结果，结果可切换、下载、复制并自动进入项目素材库。
- 音频的音色和 0.5–2.0 合法语速进入真实 TTS 请求，非法语速在路由层拒绝；图片/视频模型、素材和项目结果继续复用短剧工厂内核。
- `/canvas/local` 单击节点内容区即可展开相同编辑器，但只保留本地草稿编辑，不伪造模型、素材和生成能力。
- 右键菜单层级高于展开编辑器，节点复制、删除和素材挂载不会被编辑器遮挡。

## 本 PR 验收用例

1. 访问 `/canvas/:id` 时，图片、视频、音频自由节点能读取已有 AI 配置中的可用模型；配置为空时仍允许输入自定义模型，不阻断原有默认模型逻辑。
2. 右键自由节点显示“复制节点”“删除节点”；复制节点落在原节点右下方、获得新 ID、不会继承运行中的任务；删除同时移除相连手动连线，撤销后可恢复。
3. 图片、视频、音频自由节点可在节点内或右键打开素材库；选中兼容素材后直接更新当前节点，不额外生成重复资产节点，并持久化 `url`、`savedAssetId` 和成功状态。
4. 选择不兼容的素材类型时，当前节点不被修改，界面给出明确错误。
5. 选中文本、图片、视频或音频自由节点时展开对应的节点编辑器；未选中时保持紧凑预览，避免所有参数面板同时铺满画布。
6. 图片节点连接到视频节点后，视频编辑器立即显示来源节点；图片已有结果时显示缩略图和“已就绪”，尚未生成时显示“等待图片”。运行视频时，同一组已就绪参考图写入 `image_url`、`first_frame_url` 和 `reference_image_urls`。
7. 原有图片、视频、音频生成请求、任务轮询、失败重试、自动入库和刷新恢复用例继续通过。
8. `/canvas/local` 空白右键可添加文本、图片、视频、音频；节点右键可复制、删除；节点仍支持内编辑、拖拽、复制粘贴、撤销重做、缩放和平移。
9. `/canvas/local` 不再展示无法执行的上传、模型配置和生成按钮，并明确它是本地草稿；不新增伪 API 或伪结果。
10. 前端目标单元测试、后端画布文本/音频测试、7 条独立项目画布 Playwright 闭环用例和生产构建通过。
11. 最终差异中不出现 `AccountAdmin`、`TenantConsole`、`BillingAdmin`、`AdminWorkspace*`。

## 明确不在本 PR 内

- LibTV Agent 面板的产品化、提示词代理或服务端编排；
- 多人协作、跟随模式、多标签编辑锁；
- 供应商尚未提供真实接口的角色库、标记、特效资产等专有能力；当前仅透传已支持的真实模型参数，不伪造结果；
- 新计费、租户、账号或管理后台能力；
- 与目标无关的画布视觉重写、相邻模块重构。
