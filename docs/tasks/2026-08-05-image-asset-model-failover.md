# 图片资产默认模型与容灾修复

## 范围

- 人物、场景、风景/全景图未显式选模型时，统一解析已验证的默认图片模型。
- 保持道具图既有默认模型解析，并让四类图片共用图片供应商容灾。
- 默认模型收到明确的未受理失败后，仅切换到已启用、已验证、已配置积分且与原模型同价的备用图片模型。
- 不修改画布交互、导航栏、节点动画、积分卡片文案或 AI 音乐服务。

## 成功标准

1. 未传模型的人物、场景和全景图任务能够创建，图片任务与积分预留写入同一个有效模型。
2. 默认图片模型返回明确 503/模型不可用时，同一任务自动改用同价备用模型并成功返回图片。
3. 未验证、停用、未配置价格或不同价格的模型不得参与自动切换。
4. 网络中断、结果未知或供应商可能已经受理的请求不得自动重复提交。
5. 本地定向测试、后端全量测试、共享生产审计、CAS 发布门禁与线上健康检查全部通过。

## 本地验证记录

- RED：未传模型的人物、场景和全景任务均复现 `模型 ID 必须是 1 到 120 个可见字符`。
- RED：默认模型明确返回 503 时复现未切换备用模型；任务显式记录默认模型时同样复现。
- GREEN：人物、场景、全景、道具及计费定向测试 14/14 通过。
- GREEN：后端全量测试 633/633 通过。
