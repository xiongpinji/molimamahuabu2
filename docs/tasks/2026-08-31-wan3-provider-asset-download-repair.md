# Wan3 参考素材下载失败修复

## 目标

修复画布 Wan3 多图参考任务把未签名平台静态素材地址提交给供应商，导致供应商下载返回 401 并报 `Failed to download` 的问题。

## 生产只读证据

- 失败任务为 5 秒、480P、16:9、启用声音、两张平台参考图。
- 供应商在提交后约 3.6 秒内访问两张参考图，Nginx 均返回 401；请求未携带 `provider_asset_expires` 与 `provider_asset_signature`。
- 该任务预扣 670 积分后已恰好退款一次，最终 held/spent 均为 0。
- 节点中仍可播放的 4 秒视频属于上一次结果，不代表本次 5 秒任务成功。

## 根因

Wan3 异步处理分支直接调用独立供应商客户端，绕过了通用视频客户端已有的素材 URL 签名步骤。数据库中的规范素材地址本身正确，问题只发生在供应商提交载荷。

## 修复边界

- 仅在 Wan3 供应商提交前为平台图片、首尾帧、参考视频和参考音频生成限时签名。
- 数据库继续保存不带时效签名的规范地址，避免持久化过期签名。
- 不改模型能力、定价、积分规则、自动重试策略或其他供应商线路。
- 本地验证阶段不调用供应商、不付费、不修改生产数据。

## 验收标准

1. 无修复时，回归测试准确失败在供应商参考图缺少签名。
2. 修复后，Wan3 直连提交载荷中的平台参考素材均带有效签名。
3. 任务快照与参考素材字段仍保持原始规范 URL。
4. Wan3、素材签名、请求快照、功能锁与增量范围相关测试全部通过。

## 当前状态

Wan3 素材签名修复已合入 PR #215。生产候选验证发现共享 external verifier
把整个 `videoService.js` 作为 ToAPIs 私人形象证据的新鲜度触发面，导致仅包含
Wan3 签名逻辑的变更也错误要求刷新 FAST/MINI 私人形象付费证据。

本轮门禁修复采用精确语义投影：只从比较输入中移除 PR #215 已审计的 Wan3
素材签名导入、helper 和提交载荷包装，其余 `videoService.js` 改动仍按原规则触发
私人形象证据新鲜度检查。回归测试同时锁定两条边界：

1. PR #215 形状的 Wan3-only 改动不再要求 FAST/MINI 新证据。
2. 私人形象绑定逻辑发生真实改动时，陈旧证据仍被拒绝。

该门禁升级使用独立六文件发布范围，包含绑定新 verifier 哈希的既有原子轮换脚本，
但不包含生产数据库、共享证据、激活脚本、
AI 音乐或任何供应商调用。本地验证通过后再提交独立 PR；生产 shared verifier
升级与 Wan3 候选激活仍需分别走受保护授权和审计流程。
