# 一键转绘资产真实媒体预览

## 背景

第二步资产审核页当前只显示“正面 / 侧面 / 背面”等文字占位块。即使角色生成已经返回可读图片，用户也看不到人物，无法完成真实人工审核。

## 本地开发范围

- 为当前租户、当前用户拥有的转绘资产提供鉴权图片预览接口。
- 接口只允许读取资产库中的图片文件，校验存储根目录、真实路径和 MIME 类型，不暴露本地绝对路径或原始静态 URL。
- 角色、场景本地化图、去人净景和物品卡片在有产物时显示真实图片；无产物或读取失败时显示明确空状态。
- 前端通过 Blob URL 展示图片，并在资产切换或组件卸载时释放 URL。

## 完成标准

1. 未实现时新增测试明确失败。
2. 同 owner 的图片预览可读取；跨租户、非法变体、越界路径和非图片资产失败关闭。
3. 角色卡存在真实 `<img>`，不再用三个文字块伪装三视图。
4. 后端定向测试、前端资产测试、前端构建和转绘浏览器回归通过。
5. 不部署、不写生产数据库、不调用付费模型。
