# 画布模型自动同步、前端名称与积分提示

## 目标

画布的文本、图片、视频、音频生成节点统一读取后台模型目录。管理员以后新增模型时，不再需要修改前端代码；模型完成连接验证并启用计费后，重新进入画布即可出现在对应节点的模型选择器中。

管理员在“运营与计费 > 模型计费”维护每个模型的“前端显示名称”。前端显示该名称，但生成请求始终提交稳定的模型 ID；未填写显示名称时依次回退到模型 ID。

## 约束

- 后台 AI 配置仍是供应商、模型 ID、默认关系和连接验证状态的数据源。
- 模型计费仍是前端显示名称、积分价格和启停状态的数据源，不新增重复配置表。
- 画布公开模型必须同时满足：配置启用、最近连接验证成功、计费启用且积分为正整数。
- 一个供应商配置中的多个模型必须逐个进入目录；同类型、同模型 ID 只显示一次。
- 画布选择器显示自定义名称，内部值和请求参数保留模型 ID。
- 独立自由节点与项目画布生成参数面板使用同一目录和显示名称。
- 连接验证不得创建付费媒体；MiniMax TTS 使用官方 Get Voice 查询验证鉴权，AIHubCC 域名即使沿用旧 `openai` 标识也只查询不存在的任务，不提交图片生成。
- 本次积分必须由目录中的真实价格、数量和视频时长计算，不在组件中写死。

## 验收标准

1. 后台已验证配置新增第二个及更多模型并完成定价后，`/canvas/model-catalog` 自动返回全部模型，无需发布前端。
2. 未验证、验证失败、停用或未定价模型不进入画布目录。
3. 管理员修改“前端显示名称”后，画布模型下拉显示新名称，生成时仍提交原模型 ID。
4. 文本、图片、视频、音频生成节点底部都显示“本次生成需 X 积分”；视频按每秒价格乘时长，图片等按数量计算。
5. 积分数字和文字使用高对比强调色、粗体，并在参数变化时实时更新。
6. 当前模型无法取得确定价格时明确显示“积分待管理员配置”，不伪造价格。
7. 节点留空跟随默认时，生成请求显式提交目录中的默认模型，保证显示积分与实际结算模型一致。
8. 本任务直接相关的后端目录、前端目录与节点专项测试通过，生产构建通过；全量测试相对固定点不得新增失败，发布前复核线上模型验证和价格状态。
