# 生图失败退款与 AIHubCC 大图请求修复

## 范围

- 图片或视频任务进入终态后，前端立即刷新积分账户。
- AIHubCC 参考图在发送前压缩，避免大尺寸本地图片导致 413。
- AIHubCC 明确失败时，后台自动切换到下一项已启用的图片模型。
- 不修改 AI 音乐服务，不启用后台标记为停用的供应商配置。

## 根因

1. 后端对新失败任务已经执行退款，但任务轮询结束后前端未统一刷新积分账户，用户会继续看到旧的冻结数。
2. 本地参考图会转成 Base64 放入 JSON；大图使请求体膨胀，超过 Cloudflare 限制后返回 413。
3. 分镜图片配置存在时，候选列表没有继续包含通用图片配置，因此首选配置明确失败后没有可切换项。

## 验收标准

- 超大本地参考图进入 AIHubCC 请求体前被压缩，测试请求体小于 3 MiB。
- 413 和上游非法 JSON 400 不向前端暴露 HTML 或嵌套原始报文。
- 413、网络失败、无效响应和明确任务失败会切换到下一项已启用图片配置；状态不确定时不切换，避免重复生成和重复供应商扣费。
- 图片或视频任务成功或失败后只触发一次积分刷新事件。
- 后端完整测试、前端相关测试和生产构建通过；线上部署前后确认无执行中的生成任务，并核对 AI 音乐服务未变化。
