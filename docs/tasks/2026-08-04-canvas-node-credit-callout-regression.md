# 画布节点预计积分醒目样式回归修复

## 现象与根因

- 生产画布的图片节点仍能正确计算并显示 `40 积分`，但底部文字退化为 11px、`#71717a` 的普通灰字，缺少先前的高对比背景、边框和粗体数字。
- 当前生产发布中的 `HomeCanvasNode.vue` 使用旧的 `billing-note` 单行模板；已提交分支中的 `billing-cost` 醒目卡片没有进入后来基于线上版本制作的增量发布，属于发布覆盖导致的样式回归，不是积分计算或计费目录失效。

## 修改范围

- 只修改自由画布共用的 `HomeCanvasNode.vue` 积分文案和样式，以及对应静态回归测试。
- 文本、图片、视频、音频四类可生成节点共用同一组件，因此统一生效。
- 不改积分价格、模型选择、生成请求、结算逻辑或其它节点布局。

## 验收标准

1. 每个可生成节点编辑器底部显示“本次预计扣除 X 积分 · N 次”。
2. 积分区域使用高对比暖色背景和边框，整体加粗，积分数字进一步放大加粗。
3. 未定价时仍明确显示“积分待管理员配置”，不伪造价格。
4. 专项测试能拒绝旧的 `billing-note` 灰字模板，并验证醒目卡片的背景、边框、粗体和数字强调样式。
5. 前端全量测试相对固定点不新增失败，生产构建通过。
6. 发布必须从实际当前线上版本复制后只覆盖目标组件及新构建产物；健康检查、错误日志和 AI 音乐进程均保持正常。
