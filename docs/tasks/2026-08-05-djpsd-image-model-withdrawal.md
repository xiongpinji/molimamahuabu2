# DJPSD 图片模型撤下

## 目标

- 从管理后台图片/分镜图片供应商预设中移除 DJPSD 图片入口。
- 从生产 `ai_service_configs` 撤下 `image-v1`、`image-v1-2k` 配置。
- 从生产积分价格配置中移除两个已失效模型，确保后台价格列表与前端画布均不再显示。
- 保留 DJPSD `video-v1` 视频配置、通用开放媒体适配器和历史生成/积分流水。

## 故障证据

- 生产画布任务 `image_generations.id=389` 使用 `image-v1-2k`，DJPSD 返回 503：其内部映射的 `gpt-image-2-medium` 在 `default` 分组无可用通道。
- 使用生产 Key 和生产图片适配器最小复测 `image-v1-2k`，再次返回相同 503 和新的供应商请求号。
- 最小复测 `image-v1`，同样被映射到 `gpt-image-2-medium` 并返回 503。
- DJPSD `/v1/models` 还声明 `image-v1-4k`，但真实创建任务返回“任务扣费规则未配置”，未生成可读取结果。
- 因三个公开图片档位均未通过真实生成，当前没有可继续展示的 DJPSD 图片模型。
- 用户失败任务 `id=389` 的 40 积分预扣状态已回读为 `refunded`。

## 变更边界

- 不修改或删除 DJPSD 视频配置及其 Key。
- 不删除历史图片任务、用户积分流水或失败证据。
- 不删除 DJPSD 图片通用客户端代码；以后只有重新完成真实生成和结果文件验证后，才能重新配置并开放。
