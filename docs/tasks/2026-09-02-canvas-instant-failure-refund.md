# 画布失败积分秒退与存量冻结返还

## 目标

- 画布调用方明确标记为 `failed` 时，在同一结算调用内退回预扣积分。
- 明确标记为 `needs_attention` / `TEXT_RESULT_UNKNOWN` 的任务继续保持冻结，避免供应商仍可能成功时重复退款。
- 按用户授权，一次性返还操作时线上全部存量冻结积分。

## 代码变更

- 场景提示词和通用文本计费的明确失败使用结构化 `failureDisposition: refund`，不再由错误文案决定是否退款。
- 视频生成记录进入 `failed` 时默认使用结构化退款；调用方显式传入的其他结算方式仍优先。
- 回归测试覆盖错误文案含“结果未知”但调用方已明确失败时的退款，以及真正 `TEXT_RESULT_UNKNOWN` 继续冻结。
