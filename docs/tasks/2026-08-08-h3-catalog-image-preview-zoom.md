# H3 目录与图片预览缩放修复记录

## 目标

1. 查明 MiniMax H3 从前端统一模型目录消失的原因。
2. 图片节点双击全屏预览后，支持 `Ctrl/Command + 鼠标滚轮` 缩放。

## 根因与处理

- H3：生产 `ai_service_configs` 仍为启用且已验证，但 `model_credit_prices.model = minimax h3` 的状态为 `disabled`，统一目录按门禁正确隐藏。2026-08-08 使用现有 Key、480P、4 秒、非人物参考图进行一次真实生成，供应商任务 `task_elIwVklACOvOZwk5diClsGq1sxEETNpq` 在 13.9 秒后明确失败，原因为“服务器暂时无可用资源，请稍后重试”。未取得可读成片前不得恢复为 `enabled`。
- 图片预览：全屏层只有静态图片，没有缩放状态和滚轮处理；全局页面缩放保护又会阻止浏览器默认缩放。新增独立预览缩放状态，只有 `Ctrl/Command + 滚轮` 时按 15% 步进缩放，范围 25%–500%，打开和关闭预览均复位到 100%。

## 验收标准

- 双击图片打开全屏预览后，修饰键加滚轮能够实际改变图片比例并显示百分比。
- 普通滚轮和视频预览不触发图片缩放。
- 关闭再打开时回到 100%。
- H3 继续保持门禁隐藏，直到同一 Key 的真实生成成功、成片可读取并完成证据记录。
