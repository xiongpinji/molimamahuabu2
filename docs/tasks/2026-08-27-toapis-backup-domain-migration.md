# ToAPIs 官方备用域名迁移

## 授权与边界

- 授权时间：2026-08-27。
- 当前允许范围：在隔离工作树内用 TDD 将 ToAPIs 官方 API 合同从 `https://toapis.com` 精准迁移到供应商公告的 `https://toapis.xyz`，并升级仓库内 shared external verifier 的 FAST/MINI 双配置合同；允许提交、推送、新建 PR、等待 Hosted CI 并在全部通过后合入 `main`。
- 当前禁止范围：不安装生产 shared verifier、不部署、不修改生产数据库或线上共享证据、不调用供应商接口、不上传素材、不付费、不激活、不触碰 AI 音乐。
- 并行边界：一键转绘由另一会话负责；本任务不纳入其未合入代码，也不修改其专用整集转绘执行脚本。

## 已取得的非生成证据

- 供应商公告声明备用官网为 `https://toapis.xyz`、API 根地址为 `https://toapis.xyz/v1`。
- 生产服务器对 `toapis.xyz:443` 的 DNS、TCP 与 TLS 校验成功，证书主机名匹配。
- 在明确授权下仅执行过一次 `GET https://toapis.xyz/v1/balance`，返回 HTTP 200 且 `success=true`；该动作没有 POST、上传、生成或扣费。
- 旧 `toapis.com:443` 在同一服务器出口不可达。

## 本地验收标准

1. 客户端默认入口和唯一允许的精确主机为 `https://toapis.xyz`；仅接受根路径或 `/v1`，拒绝旧 `.com`、子域、凭据、端口、查询、片段、HTTP 和伪造相似域名。
2. 管理员 ToAPIs 预设与帮助文本展示 `https://toapis.xyz`。
3. 标准验证脚本、私人形象验证脚本、证据合同审计器和共享外部模型验证器源码统一绑定 `provider_origin=https://toapis.xyz`。
4. 不自动回退到旧 `.com`，未知提交仍保持 `needs_attention`、不自动重试的既有合同。
5. 定向测试、相关回归、功能锁审计和差异审计通过；本阶段不以只读连接测试冒充真实生成可用性。

生产变更必须另行授权，并从操作时实时 `/opt/moli-drama/current` 构建受保护候选；共享验证器升级、共享证据刷新、配置 16/27 的数据库绑定、真实付费生成和解除暂停必须分阶段审查与授权。

## shared external verifier 双配置合同升级

- FAST/MINI 真实验证必须分别提供两个有效且不同的配置 ID；在读取供应商 Key 前，先以只读数据库连接核对两条配置均为对应模型的专用 ToAPIs `.xyz` 视频线路。
- 付费前快照对线路 ID、协议、域名、Key、模型、端点、settings、启用/暂停/故障转移状态做 SHA-256 指纹；最终发布前在同一 SQLite `IMMEDIATE` 事务内重读并比对，任一漂移即拒绝绑定旧证据。
- 最终证据文件、两个配置 ID 和两个配置快照必须同时进入发布调用；两条配置只保存各自模型能力并绑定相同的最终证据合同/SHA。第二条写回或回读校验失败时，数据库事务回滚并恢复原证据文件。
- 共享外部模型门禁新增 FAST/MINI 缺失、重复、凭据顺序、快照缺失、指纹缺项、配置漂移、最终调用缺项和失败降级等破坏性变异测试；结果为 100 项中 97 通过、3 项仅按 Windows 能力跳过、0 失败。
- ToAPIs 验证脚本测试 32/32、受保护发布合同 18/18、共享门禁轮换 40/40、功能锁与增量范围 35/35 均通过；功能锁审计相对 `origin/main` 返回 `ready=true`，本轮 6 个变更路径未触及任何 `protectedPaths`，因此未改功能锁。
- 仓库可信源码哈希与轮换脚本固定哈希已同步更新。本阶段只允许推送、PR、Hosted CI 和合入 `main`；没有生产安装、生产数据库/共享证据写入、供应商调用、上传、生成、付费或激活。
