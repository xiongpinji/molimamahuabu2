# Token6688 参考素材直链修复

## 现象

- 短剧工厂使用 Token6688 Seedance 时，供应商返回 HTTP 400：参考素材无法访问。
- 生产失败记录 186 的参考图已经是完整 `https://molimama.vip/static/...` 地址，不是相对路径。
- 对该地址从公网和服务器本机匿名请求均返回 HTTP 401；带登录态的浏览器可以显示，所以供应商无法拉取。

## 根因

公开平台模式下，`/static` 由资源归属中间件保护。Token6688 收到的普通静态素材 URL 不带用户会话，供应商下载时被拒绝。

## 修复

- 平台向 Token6688 发送自己的静态素材时，生成 2 小时有效的 HMAC-SHA256 签名 URL。
- 签名绑定素材路径和到期时间，路径被修改、签名被修改或链接过期均继续返回 401。
- 未签名的 `/static` 请求继续执行原有用户身份和资源归属校验；没有公开整个素材目录。
- 同一转换链覆盖 Token6688 图片、视频和音频参考素材。

## 验收

- 原始最小复现：出站请求携带普通 `/static` URL，回归测试失败。
- 修复后：签名 URL 可匿名读取目标文件；未签名、篡改路径和过期 URL 均返回 401。
- Token6688 图片和视频请求测试确认出站参考素材使用有效签名 URL。
- 相关鉴权、资源归属、上传、模型路由测试全部通过。
- 上线后必须使用生产素材验证匿名下载，再完成一次 Token6688 实际参考视频任务并读取结果文件。
