# 分镜资产重匹配修复记录（2026-07-31）

## 问题与根因

- 角色重新提取后，旧角色记录被软删除，但已有分镜仍保存旧角色 ID。
- 分镜生成只信任 AI 返回的资产 ID，原有同步逻辑只追加文本命中的角色，不会迁移或移除失效 ID。
- 场景、物品缺少同一套有效性校验；分镜轻量刷新也没有返回 `prop_ids`。

## 本次范围

- 统一校验当前集每条分镜关联的角色、场景和物品。
- 保留仍有效的人工选择。
- 按同名资产迁移软删除的旧关联，并按分镜文本补充当前有效资产。
- 分镜生成完成后自动执行一次统一匹配。
- 在分镜生成区增加“强制匹配场景/角色/物品”按钮，操作前要求确认。
- 强制匹配只处理当前集，不调用 AI、不扣积分。

## 验收标准

- 失效角色、场景、物品 ID 能迁移到同名的当前有效资产。
- 分镜文本明确提到的有效资产能够补齐。
- 仍有效的人工选择不会被删除。
- 没有场景线索时不应误选任意场景。
- 生成轮询返回物品关联，避免前端把选择清空。
- 后端路由、前端按钮、生产构建及短剧工厂相关测试通过。
