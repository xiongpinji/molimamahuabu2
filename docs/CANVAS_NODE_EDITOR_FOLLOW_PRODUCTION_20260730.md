# 画布节点编辑器跟随与参考图右键引用

## 用户反馈

1. 节点编辑器与当前节点位置分离。
2. 编辑器内容没有完整保持在可用视口内。
3. 视频节点的参考图需要支持右键直接写入对应 `@图片N`。

## 修改边界

- 仅修改自由画布节点编辑器、本地画布聚焦入口和对应回归测试。
- 编辑器继续挂载到 `body`，避免被画布缩放或节点容器裁切。
- 保留现有主线的视频参考模式、图片工具栏、全屏编辑和 `@` 选择菜单。
- 生产发布只允许操作 `/opt/moli-drama` 与 `moli-drama.service`；不得触碰 AI 音乐的 `/opt/moli-mama`、PM2 进程和 Nginx 路由。

## 验收标准

1. 拖动节点、平移或缩放画布时，非全屏编辑器持续锚定当前节点，节点与编辑器间距为 12px。
2. 编辑器自动选择节点上方或下方空间更充足的一侧，完整保持在视口内；内容超出时仅编辑器内部滚动。
3. 右键视频节点第 N 张参考图后，描述光标处（未记录光标时为末尾）写入 `@图片N` 并保存。
4. 全屏编辑、原有 `@` 菜单、参考图移除和生成参数不回归。
5. 从节点编辑器打开配置弹窗后，弹窗高于编辑器且“保存修改”可正常点击。
6. 图片工具条及其下拉菜单不被编辑器遮挡；按 Esc 关闭后不会被延迟单击再次打开。

## 缩放自适应补充

### 用户反馈

- 画布缩放到 20% 后，节点已经缩小，但编辑器仍保持固定 `860px`，遮挡大面积画布。

### 验收标准

1. 编辑器尺寸跟随节点在画布中的实际缩放比例变化。
2. 20% 画布缩放时，编辑器宽度为 `516px`，最大高度不超过 `384px`。
3. 100% 画布缩放时，编辑器保留 `860px` 的完整尺寸。
4. 编辑器最低保留 60% 的可操作尺寸，继续锚定节点并保持在视口内，内容超出时内部滚动。

- `npm run test:e2e:canvas`：37 项通过，1 项付费供应商同链按环境条件跳过，0 项失败。
- `npm run build`：通过。
- 静态源码契约测试有 2 项主线既有断言漂移：`镜头运动` 已改为 `视频运镜`，旧滚轮缩放属性已移除；均不在本次修改范围。
