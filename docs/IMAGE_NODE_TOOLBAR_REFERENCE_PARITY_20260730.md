# 图片节点编辑栏参考站交互补齐

日期：2026-07-30

## 范围

本轮以登录态参考站图片节点工具栏的实际交互为依据，补齐本地图片编辑体验。保留现有真实任务接口和新素材回写链，不复制参考站私有代码。

明确不在本轮范围：

- 核验 / 版权检测
- 对口型
- 在参考站提交生成任务或消耗积分

## 参考站实测

### 工具入口

- 快捷入口：720 全景、灯光、高清。
- 工具菜单：裁剪/压缩/镜像、标记修图、宫格裁剪、智能抠图、框选抠图、图片调整、LUT 调色、生成导演台、姿势、角度、扩图、画面联想、角度联想。
- 设定菜单：生成全景场景、角色三视图、多机位叙事九宫格、画面推演、电影级光影校正、细节纹理增强。
- 公共动作：处理历史、替换、下载、全屏。

### 交互规律

- 顶部工具栏为深色圆角胶囊，入口使用“图标 + 文本”；工具、设定菜单通过悬停打开并在鼠标进入面板后保持。
- 工具菜单为单列图标菜单；能力不可用时禁用，不额外插入“未接通”文案破坏菜单对齐。
- 编辑不是只有参数表单，而是独立的大尺寸工作区。
- 原图或处理结果占主要区域，参数集中在侧栏。
- 本地可计算效果应即时预览，生成型能力保留原图作为参考。
- 取消和应用固定在统一出口；应用后生成新素材，不覆盖原图。
- 灯光是独立工作台，包含场景方向、灯位、预设、灯光列表、硬/柔光、强度、颜色和重置。

### 已核对的独立工作台

- 标记修图：选择/移动、画笔、直线、箭头、矩形、圆形、马赛克、数字标记、文本；颜色、字号/大小/强度/粗细、撤销/重做、图层排序/显隐/删除、清空、教程，以及“仅确认标记”和“标记并修改”两种出口。
- 宫格裁剪：自动检测、手动网格、自由裁剪；可拖动或双击删除辅助线、全选/取消全选、独立导出选中区域或保留原图尺寸并遮罩未选区域。
- 框选抠图：矩形与画笔两种选区方式；松手分析、清空、重试、透明 PNG 导出。
- 图片调整：光线、颜色、细节、效果、曲线五组；原图/调整后对比、参考图色彩匹配、预设、重置和实时预览。
- LUT 调色：推荐/最近/分类 LUT、上传 3D LUT、强度、手动调色、原图/调色后对比、重置。
- 灯光调节：18 个布光预设；灯光列表可增删；硬光/柔光；强度 0–10；预设色和自定义色；场景、水平、垂直方向控制与重置。
- 角度调整：3D 预览；水平旋转、垂直倾斜、远近距离三类控制；旋转角度、前进距离、垂直倾斜参数组与重置。
- 姿势：可拖拽关节点，支持多选和框选；21 个姿势预设、参考图上传与重置。
- 扩图：自由扩边和常用目标比例；分别控制上、下、左、右扩展区域，保持原图中心内容。
- 画面联想/角度联想：保留原图预览，标签选择与自定义提示词；切换标签会确认是否覆盖已编辑提示词。

## 本轮成功标准

- 所有非裁切类图片参数编辑器具有清晰的左侧预览和右侧参数区。
- 图片调整、LUT、镜像、旋转和宫格裁剪在提交前可即时看到效果。
- 生成型能力明确显示原图参考及“不覆盖原图”的结果语义。
- 裁切、框选抠图、标记修图继续使用适合其操作的大画布。
- 对口型入口不再出现。
- 原有任务提交、失败保留、重试、历史、替换、下载、全屏链路不回归。

## 验证门禁

1. 组件静态测试覆盖工作区结构、实时预览和排除项。
2. 浏览器测试覆盖裁切尺寸、参数预览变化、成功回写、失败保留与重试。
3. 前端测试与生产构建通过。
4. 审计改动范围，不提交 `.worktree-ports.json` 或无关文件。
5. PR 的 CI 全绿后才允许备份并更新线上。
