# 画布项目中心第三阶段：文件夹、筛选与排序

## 目标

- 当前租户可创建、重命名和删除项目文件夹。
- 画布项目可归入文件夹，也可恢复为“未分类”。
- 项目中心可按文件夹筛选，并与画布项目类型和关键词搜索组合使用。
- 项目中心可按最近更新、创建时间或项目名称排序。

## 实现约束

- 继续复用唯一的 `DramaCanvas.vue`，不复制或修改画布引擎。
- 文件夹数据必须按当前租户隔离；任何跨租户读取、修改或项目归档均返回不存在。
- 删除文件夹只解除项目关联，不删除项目。
- 排序字段使用后端白名单映射，不接受客户端 SQL 片段。
- 本阶段使用明确的选择器和管理弹窗，不加入拖拽整理。
- 本阶段不实现版本快照、自动保存恢复或多人实时协作。

## 验收标准

1. 数据迁移可为新旧数据库建立 `project_folders` 和 `dramas.folder_id`。
2. 文件夹增删改查和项目归档均受租户边界约束。
3. `project_type + keyword + folder_id + sort` 可同时生效。
4. 删除文件夹后，原项目仍存在并归入“未分类”。
5. 前端提供全部、未分类和具体文件夹筛选，提供三种排序方式及项目移动入口。
6. 聚焦测试、前后端全量测试、前端构建和浏览器验收均通过。
