# OpenVideo 前端对齐契约

## 边界

- 保留“茉莉妈妈”品牌、现有项目数据、素材库和真实生成接口。
- 对齐 OpenVideo 的信息层级、深色视觉、黑橙强调色、画布节点形态和交互路径。
- 不复制对方商标、图片资产、文案或未公开接口。

## 当前阶段验收

1. 全局工作区不再使用紫色渐变与悬浮胶囊导航，统一为黑色背景、细边框和橙色交互强调。
2. 项目首页使用紧凑顶栏、清晰模式导航和深色项目卡片；“新建”保持主要操作。
3. 项目画布与独立画布使用一致的顶部工作区壳层、底部工具栏和节点选择色。
4. 独立画布通过顶栏、底部工具栏或右键创建节点时，节点立即出现在画布中，不再先弹表单。
5. 文本、图片、视频节点继续在节点内部编辑；拖拽、连线、撤销、重做、Ctrl/⌘+滚轮缩放和 Space 平移不回退。

## 后续阶段

- 首页营销首屏及模型展示区。
- 短剧流水线各业务页面的卡片、表单与状态反馈逐页统一。
- 移动端画布与素材面板专项适配。
