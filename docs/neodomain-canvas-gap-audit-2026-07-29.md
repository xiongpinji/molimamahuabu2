# NeoDomain 画布交互对比记录（2026-07-29）

## 本轮目标

为茉莉妈妈画布补齐 NeoDomain 连线中点剪线交互，并保留撤销、保存和恢复能力。

## 本轮已交付

- 连线悬停或选中时，在连线中点显示圆形剪刀按钮。
- 点击剪刀立即删除该连线。
- 自动生成的连线被剪断后写入 `suppressed_edge_ids`，刷新后不会自动重建。
- 手工连线删除后同步保存当前连线集合。
- 剪线动作进入画布历史，可通过撤销恢复。
- 直线、折线和贝塞尔线继续使用原有渲染模式。
