# 图片节点工具栏 P8：标记修图验证报告

## 范围与结论

- 本阶段只实现“标记修图”，不包含核验、侵权检测或版权判断。
- 前端使用原生 SVG Pointer Events 采集受限笔迹；后端用现有 Sharp 生成临时标记图。
- 生成层复用 P6 已审计的 Volcengine Seedream 参考图适配器，同时提交原图和标记图。
- 能力只有在本地模式、默认参考图配置显式设置 `supports_markup_retouch=true`，且命中已审计协议时开放。
- 公开平台模式固定禁用，未接通的灯光、姿势、角度、扩图等能力仍显示“未接通”。
- 原素材不覆盖；成功结果写入新的派生素材、异步任务和节点处理历史。

## 官方依据与边界

- 火山引擎 Seedream 4.0-5.0 提示词指南说明图片编辑支持箭头、线框、涂鸦等视觉信号和多图输入：
  <https://www.volcengine.com/docs/82379/1829186>
- 火山引擎 Seedream 图像生成处理器文档说明支持一张或多张参考图：
  <https://www.volcengine.com/docs/6492/2221472?lang=zh>
- 本阶段没有复制第三方私有实现，也没有新增运行时依赖。
- “支持参考图”不会自动开放标记修图；配置必须显式声明 `supports_markup_retouch=true`。
- 自动能力声明只允许已核对请求体的 Volcengine Seedream 路径，其他协议继续不可用。

## 实现与隔离

- 前端限制：
  - 最多 16 条笔迹；
  - 每条最多 128 个归一化坐标点；
  - 只允许 5 个标记颜色；
  - 指令必填且最多 500 字；
  - 支持撤销一笔和清空；
  - 对话框销毁时清理编辑状态。
- 浏览器实测发现并修复两个交互精度问题：
  - SVG 覆盖层原先比预览图高约 11px，现已与预览图同为 `485 × 272.8125` CSS 像素；
  - 活动笔迹改为引用响应式数组中的对象，避免拖动预览只显示起点。
- 后端重新执行全部数量、颜色、宽度和坐标白名单校验，前端输入不作为信任边界。
- 临时标记图写入项目派生目录，供应商调用结束后无论成功失败都删除。
- 供应商请求固定包含两张参考图：
  - 图一：未修改原图；
  - 图二：叠加标记的临时参考图。
- 提示词固定要求只修改标记区域、移除全部彩色标记、保持区域外内容不变。
- 供应商输出必须通过受限 URL/data URL、64 MiB、格式、像素、画幅误差和可解码性校验。
- 最终输出统一为与源图相同宽高的 PNG；源图字节保持不变。
- 供应商错误和内部细节统一脱敏为“标记修图处理失败”；损坏源图只返回受控的格式错误，不暴露 Sharp 文本或本地路径。
