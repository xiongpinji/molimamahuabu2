- P15-A 来源选择和本机运行门槛审计已完成。
- MuseTalk 是当前唯一通过初步商业许可筛选的本地开源候选。

- 当前开发机未检测到 `nvidia-smi`，不具备 MuseTalk 真实推理验证条件。
- `lip_sync` 继续保持“对口型模型能力尚未配置”，未开放按钮、未新增假处理器，也未复用普通图生视频冒充对口型。
- P15-B 真实处理链尚未完成。
- 未推送、未创建 PR、未同步线上服务器。

## 线上架构修订

项目实际部署在不支持 GPU 的轻量服务器，因此 MuseTalk 不再作为线上运行时。

P15-B 改为接入 HeyGen 官方 v3 Videos API：

- 任意人物图片作为 `type=image` 输入；
- 使用现成音频的 `audio_url` 或 `audio_asset_id`；
- 保存异步 `video_id` 并轮询完成状态；
- 下载最终 MP4 到项目素材目录后再创建视频派生资产。

该路线不要求服务器 GPU，但会把图片和音频发送给第三方，并产生供应商费用。
在取得隔离验证密钥、确认计费与数据条款并完成真实 API 验证前，`lip_sync`
仍保持不可用。
