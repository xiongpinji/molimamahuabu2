# 图片节点工具栏 P10：3D 机位角度预演规格

## 1. 范围

本阶段只补齐图片节点“工具 → 角度”：

- 复用现有 3D 导演台、真实相机对象、构图预设、FOV、画幅和机位持久化链。
- 从图片节点进入时携带当前图片作为构图参考。
- 进入导演台动画工作区；存在真实机位对象时直接选中并定位到相机检查器。
- 尚无真实机位对象时不静默创建数据，只聚焦现有“添加机位”动作，由用户明确添加。
- 明确提示这是 3D 机位角度预演，不直接修改源图片；用户可用既有机位截图生成新素材。

本阶段不实现：

- 核验、侵权检测、版权判断；
- 图片模型重绘、角度联想或把参考图人物转换为 3D 对象；
- 姿势、全景、联想、推演、三视图、九宫格、对口型；
- 新增模型、权重、服务依赖或导演状态格式。

## 2. 方案取舍

采用现有 `director-stage` 引擎：

- 项目已有真实 Three.js 相机对象、导演视角和机位视角；
- 现有相机检查器支持位置、旋转、构图预设、FOV、画幅、跟随、注视目标和辅助线；
- 机位修改已经通过 `director_timeline -> canvas_layout` 持久化；
- 机位截图走既有素材回写链且不覆盖原图。

本阶段不接图片角度生成模型。没有经过许可、供应商协议、真实输入输出和产物审计的模型，不得把“角度”宣称为图片换视角。

## 3. 交互

1. 后端能力接口将 `angle` 声明为：
   - `available=true`
   - `engine=director-stage`
   - `action=open`
   - `mode=angle`
2. 图片节点“角度”只在能力可用且节点不忙时可点击。
3. 点击后复用 `openDirectorStage`，传入当前图片 URL、节点 ID 和标题。
4. 导演台进入动画工作区和导演视角。
5. 若 `activeCameraId` 对应一个实际存在且 `type=camera` 的真实机位对象：
   - 选中该机位；
   - 定位到相机检查器。
6. 若当前只有无场景对象的旧导演相机、悬空 `objectId` 或 `objectId` 指向非相机对象：
   - 不自动新增或持久化数据；
   - 聚焦“添加机位”，等待用户明确操作。
7. 其他导演台、灯光入口行为保持不变。

## 4. 验收

- `angle` 只打开导演台，不调用图片派生 API。
- `angle_ideation` 继续不可用。
- 导演台图片入口只接受 `director_stage`、`lighting` 和 `angle`。
- 角度入口显示当前参考图和“不直接修改原图”的说明。
- 新建机位后，构图预设、FOV、画幅、位置和旋转连接真实相机对象。
- 悬空和错类型机位对象引用均由可执行自动化测试验证为“添加机位”降级。
- 状态变化继续走既有画布布局保存链，刷新后可以回读。
- 原图 URL、资产 ID 和文件保持不变。
- 前后端专项、全量测试和前端构建通过。
- 生产代码没有核验、侵权或版权判断入口。
