# 图片节点工具栏 P9：灯光导演台规格

## 1. 范围

本阶段只补齐图片节点一级入口“灯光”：

- 复用现有 3D 导演台、真实环境光/方向光和导演状态持久化链。
- 从图片节点进入时携带当前图片作为构图参考。
- 直接定位到 3D 场景灯光控制区域。
- 明确提示这是 3D 灯光预演，不直接修改源图片；用户可用现有截图能力生成新素材。

本阶段不实现：

- 核验、侵权检测、版权判断；
- “电影级光影校正”或任何冒充模型重绘的静态结果；
- 姿势、角度、全景、联想、推演、三视图、九宫格、对口型；
- 新增模型、权重、服务依赖或新的导演状态格式。

## 2. 方案取舍

采用现有 `director-stage` 引擎，而不是在图片工具服务中新增假灯光处理器：

- 导演台已经用真实 3D 环境光、方向光和可添加灯光对象驱动场景；
- 导演状态已进入画布布局保存链，灯光变化可恢复；
- 导演台已有截图回写素材能力，且不覆盖源图；
- 复用现有链只需增加一个受限入口模式，改动范围最小。

IC-Light 暂不接入本阶段。官方 V2 明示非商用；V1 示例使用的 BRIA RMBG 1.4 也被官方标注为非商用，必须先替换抠图实现并单独完成代码、模型权重、依赖和真实运行审计。

## 3. 交互

1. 后端能力接口将 `lighting` 声明为：
   - `available=true`
   - `engine=director-stage`
   - `action=open`
   - `mode=lighting`
2. 图片节点“灯光”只在能力可用且节点不忙时可点击。
3. 点击后调用现有 `openDirectorStage`，传入：
   - `mode=lighting`
   - 当前图片 URL
   - 图片节点 ID 和标题
4. 导演台进入场景模式，清除对象选择并把属性检查器定位到环境灯光控制。
5. 页面显示“3D 灯光预演，不直接修改原图”的说明。
6. 其他导演台入口继续使用 `mode=director_stage`，行为不变。

## 4. 验收

- `lighting` 与 `director_stage` 都只走打开导演台的前端动作，不调用图片派生 API。
- 图片节点悬停或选中时工具栏在真实页面可见，样式修复不影响其他节点。
- `cinematic_relight` 继续不可用。
- 导演台只接受 `director_stage` 和 `lighting` 两种图片节点入口模式。
- 灯光入口显示当前参考图，并定位到环境光/方向光控制。
- 状态变化继续通过既有 `state-change -> director_timeline -> canvas_layout` 保存。
- 原图 URL、资产 ID 和文件保持不变。
- 前端专项、后端图片工具专项、前后端全量测试和前端构建通过。
- 禁区扫描确认生产代码中没有核验、侵权或版权判断入口。
