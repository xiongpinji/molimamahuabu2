# 一键转绘海外短剧设计规格

## 1. 文档状态

- 状态：交互设计和实现计划已确认，等待执行方式选择。
- 日期：2026-08-06。
- 产品：茉莉妈妈 2。
- 功能入口：一键转绘。
- 核心目标：把中国短剧转绘为面向指定海外语言和地区的短剧成片。
- 本地化策略：忠实本地化。
- 生成门禁：用户必须确认角色、场景、物品和音色后，系统才能批量生成视频。

## 2. 背景与调研结论

本设计基于对已登录竞品中一个已完成转绘项目的只读调研。调研只读取可见页面、步骤状态和可见产物，不读取 Cookie、密钥或本地存储，不提交新任务，不消耗竞品积分。

竞品采用以下 4 步工作流：

1. 原片输入：上传 MP4、MOV 或 ZIP，选择目标语言、画面风格和尺寸比例。
2. 资产详情：管理角色、场景、物品和角色声音；角色卡片包含原图、三视图、版本和确认状态。
3. 分镜管理：按批次和 10 至 15 秒左右的分镜段生成新视频；提示词通过 `@角色`、`@场景` 引用资产，并描述开场状态、连续动作和镜尾状态。
4. 视频编辑：把分镜段放入时间线；支持原片对比、字幕开关、重新拼接、下载和剪映导出。

茉莉妈妈 2 已具备可复用的剧本分析、角色、场景、道具、分镜提示词、视频异步任务、视频合并、音频、素材库、积分账本和任务恢复能力。当前缺少的是以源视频为入口的独立转绘项目、自动拆镜、本地化版本、资产审核、镜头级重绘和成片时间线编排。

本功能复刻竞品的产品行为、页面结构、步骤顺序和交互反馈，不复制竞品源码、商标、品牌资产或受版权保护的素材。

## 3. 目标与非目标

### 3.1 目标

- 提供竞品级的「转绘项目 → 转绘作品 → 四步工作台」完整流程。
- 支持单个视频和 ZIP 批量视频输入。
- 自动识别镜头、角色、场景、物品、对白、字幕、屏幕文字和动作承接。
- 以目标语言和地区驱动人物命名、文化表达、台词、配音、字幕和画面提示词。
- 保留剧情事实、人物关系、因果、反转和集尾钩子。
- 支持镜头级预览、编辑、生成、重试和原片对比。
- 支持断点恢复、幂等计费、失败释放积分和产物版本化。
- 输出可下载成片、字幕文件和可编辑剪映导出信息。
- 允许把确认后的转绘结果导入现有短剧工厂，但不得直接覆盖原项目。

### 3.2 非目标

- 首版不提供自由改写剧情或重构人物关系。
- 首版不替代现有短剧工厂和自由画布。
- 首版不在转绘工作台中提供完整非线性剪辑器，只提供分镜级轻量时间线。
- 未通过真实生成验证的模型、语言或音色不得显示为「完整出片」能力。
- 本设计阶段不执行模型配置变更、数据库迁移、生产部署或积分调整。

## 4. 核心术语

| 术语 | 定义 |
| --- | --- |
| 转绘项目 | 一组面向同一海外市场的短剧作品，例如「拉美都市复仇剧」。 |
| 转绘作品 | 一个源视频或 ZIP 中的一个视频，对应一集或一个片段。 |
| 源片事实层 | 从原片提取且不可被本地化改写破坏的事实、关系、时间码和动作合同。 |
| 本地化版本 | 同一作品在特定语言、地区和策略下生成的一组台词、资产、分镜和成片。 |
| 资产审核 | 用户确认本地化角色、场景、物品和音色的强制门禁。 |
| 分镜任务 | 一个具有独立时间码、提示词、引用资产、视频生成任务和产物的镜头段。 |
| 完整出片 | 目标语言的文本改写、配音、字幕和视频模型均通过真实生成验证。 |
| 仅字幕 | 文本和字幕可生产，但没有通过门禁的目标语言配音能力。 |

### 5.1 全局入口

在现有主导航中增加「一键转绘」，与「短剧工厂」「剧本分析」「画布」「素材库」同级。

### 5.2 路由

| 路由 | 用途 |

| `/redraw` | 转绘项目和转绘作品列表。 |
| `/redraw/:projectId/work/:workId?step=1` | 四步工作台；刷新后恢复当前步骤。 |

3. 打开作品进入四步工作台。面包屑固定为「转绘项目 / 转绘作品 / 作品名称 / 版本编号」。

## 6. 四步工作台

### 6.1 第 1 步：原片输入

#### 输入合同

- 单视频支持 MP4 和 MOV，时长为 15 秒至 60 分钟。
- ZIP 内只允许 MP4 和 MOV；每个视频时长为 15 至 180 秒，最多 20 个。
- 服务端必须校验 MIME、文件头、时长、分辨率和文件大小，不能只依赖扩展名。
- 上传完成后创建只读源资产和内容指纹。重复上传同一文件时提示复用，不静默创建重复作品。

#### 必填设置

- 目标语言。
- 目标地区。
- 本地化策略，首版固定为「忠实本地化」。
- 画面风格：二维动漫、三维动漫、真人写实或自由风格。
- 尺寸比例：`1:1`、`9:16`、`16:9`、`3:4`、`4:3`、`21:9`。

#### 风格选择器

风格选择区域按竞品已观察到的结构实现：

- 顶部显示「二维动漫风」「三维动漫风」「真人写实风格」「自由风格」4 个大类按钮。
- 大类下方显示横向滚动的图片卡片。卡片保持稳定尺寸，使用圆角预览图、底部名称覆盖层和明确的选中边框。
- 支持鼠标滚轮、触控板、触摸拖动和键盘左右方向键横向浏览，滚动时不得压缩卡片或改变表单高度。
- 切换大类时保留各大类最近浏览位置；切换作品或刷新时恢复已保存的风格选择。
- 点击预设卡片保存 `style_preset_id` 和预设版本快照。预设内容后续更新不能静默改变已提交版本。
- 「自由风格」显示自定义正向提示词、负向提示词和参考图入口，不同时选中普通预设。
- 用户在资产或分镜生成后修改风格时，系统创建新的本地化版本，并明确标出需要重新生成的资产和分镜，不能覆盖上一版产物。

真人写实风格首批预设完整包含：

| 分组 | 风格预设 |
| --- | --- |
| 基础与东方题材 | 默认风格、古典武侠风、宫斗权谋冷峻风格、国产悬疑冷调、古偶唯美柔光、国产都市写实、武侠江湖写实摄影风格、90 年代中国农村电影风格、中式暖调蓝辉风格、90 年代港片风格。 |
| 日韩题材 | 日式青春胶片、日式生活自然、日本黑白胶片摄影风格、韩剧都市柔光、韩国冷淡风电影风格。 |
| 欧美与复古题材 | 复古科幻原子朋克、90 年代写实电影风格、复古叙事电影风格、美式复古好莱坞、老式工业影视风格、复古战争电影风格、复古电影摄影风格、美式复古怪异影视风格、美式经济上行风格、美式复古影视风格、好莱坞黑白电影风格。 |
| 类型与色彩题材 | 霓虹赛博电影风格、荒野电影风格、橙黄色电影风格、恐怖电影风格、荒诞高调白色色调电影风格、蓝橙色调影视风格、工业电影风格、科技感电影风格、悬疑电影风格、希腊神话电影风格、紫色色调电影风格。 |

二维动漫风和三维动漫风使用相同的分类、卡片、版本和门禁合同。首批具体预设必须来自已配置模型的真实生成证据，不能用未验证的静态卡片冒充可生产风格。

每个风格预设包含：

- 稳定 ID、名称、大类、排序和版本。
- 正向提示词模板和负向提示词模板。
- 自有、获授权或生成的预览图资产，禁止直接复制竞品缩略图。
- 兼容模型、支持比例和输入限制。
- `draft`、`verified` 或 `disabled` 状态。
- 不含密钥的真实生成证据，包括模型、任务 ID、成功终态和可读取结果资产。

只有 `verified` 预设出现在普通用户目录。`draft` 和 `disabled` 预设不得进入前端生产目录。

#### 提交行为

- 提交前由服务端生成分析报价快照。
- 页面显示醒目的「本次预计扣除 X 积分」。未定价时显示「积分待管理员配置」并禁止提交。
- 「开始分析并进入资产详情」创建持久化任务。页面刷新和服务重启后继续回读真实状态。

### 6.2 第 2 步：资产详情

#### 资产类型

- 角色：原图、本地化名称、角色描述、三视图、版本、音色和确认状态。
- 场景：源场景、本地化场景、地区化描述、版本和确认状态。
- 物品：源物品、本地化物品、屏幕文字替换、版本和确认状态。

场景资产额外支持“去人净景”：从源场景代表帧生成可审计的人物遮罩，再生成移除人物后的 clean plate。源场景、本地化场景和 clean plate 独立版本化；净景生成必须记录遮罩、输入帧指纹、模型、任务和结果资产，结果仍需用户人工确认。引用净景的分镜必须审批对应净景版本，去人失败只影响该净景尝试，不删除或覆盖源场景。

#### 卡片操作

- 预览源资产与本地化资产。
- 查看和切换版本。
- 编辑名称、描述、提示词和地区化映射。
- 单项重绘、批量重绘或上传替换。
- 选择或上传角色声音。
- 确认或退回资产。
- 持续显示生成状态和本次预计扣分。

#### 强制审核门禁

进入批量视频生成前，所有被分镜引用的角色、场景、物品和角色音色必须处于 `approved` 状态。任一必需资产未确认时：

- 可以继续编辑提示词和分镜。
- 不得提交单镜或批量视频生成。
- 页面必须显示缺失项和返回资产卡片的直接入口。

### 6.3 第 3 步：分镜管理

#### 页面结构

- 左侧或顶部显示批次和源视频缩略图。
- 主预览区支持「原视频 / 新视频」切换和同时间码对照。
- 提示词编辑器支持 `@角色`、`@场景`、`@物品` 和参考视频引用。
- 下方显示分镜缩略图、编号、时长、生成状态和错误状态。
- 右侧显示模型、时长、清晰度、数量和积分预估。

#### 分镜合同

每个分镜至少包含：

- 源片起止时间码。
- 开场状态。
- 连续动作和表演节拍。
- 镜尾状态。
- 镜头类型、运动、构图、光线和氛围。
- 角色、场景和物品引用。
- 源台词、本地化台词、说话人和可说时长。
- 画面提示词、负面提示词和模型编译提示词。
- 原视频段、新视频段、配音和字幕产物引用。

#### 生成行为

- 单镜生成只冻结和结算该镜头的积分。
- 批量提交只包含通过门禁且未完成的镜头。
- 同一分镜、版本和生成参数使用稳定幂等键，重复点击不重复扣费或创建供应商任务。
- 单镜失败不影响其他镜头预览、重试或最终合成。

### 6.4 第 4 步：视频编辑

#### 页面结构

- 成片播放器显示当前成片版本、时间码和音量。
- 时间线按顺序展示全部分镜段。
- 支持原片对比、字幕开关和外语配音开关。
- 允许重新排序、替换和禁用分镜，但不提供首版范围外的多轨自由剪辑。

#### 操作

- 重新拼接：只使用现有分镜、音频和字幕重新合成，不重新生成镜头。
- 下载：下载当前成片版本。
- 字幕导出：下载 SRT 和 VTT。
- 剪映导出：生成包含镜头、配音、字幕、时间码和素材引用的工程归档。只有该归档能被任务指定的剪映桌面版本实际导入并打开，才算导出成功；版本不兼容时显示不可用，不能只下载一个未验证的 JSON 文件。
- 导入短剧工厂：创建或更新明确的目标项目版本，不覆盖源片或原短剧项目。

## 7. 海外本地化合同

### 7.1 源片事实层

系统从源片中提取：

- 镜头和时间码。
- 角色身份、关系和说话人。
- 原台词、画外音、字幕和屏幕文字。
- 地点、时间、关键道具和动作。
- 因果链、关键证据、反转和集尾钩子。

源片事实层版本化保存。本地化版本只能引用事实层，不能覆盖事实层。

### 7.2 忠实本地化

允许修改：

- 人名、称谓和礼貌等级。
- 俚语、口语、语序和句长。
- 货币、计量单位、节日、机构名称和社会语境。
- 场景装饰、服化道、屏幕文字和字幕排版。

禁止修改：

- 人物关系和核心动机。
- 因果、关键证据和动作结果。
- 时间线、反转和集尾钩子。
- 用户锁定的事实。

### 7.3 语言目录

首屏提供以下语言：

- 英语、西班牙语、葡萄牙语、法语、德语和意大利语。
- 日语、韩语、阿拉伯语和印地语。
- 印尼语、泰语、越南语、土耳其语和俄语。

支持主要地区变体：

- 英语：美国、英国。
- 西班牙语：拉美、西班牙。
- 葡萄牙语：巴西、葡萄牙。
- 法语：法国、加拿大。
- 阿拉伯语：现代标准语，以及通过真实配音验证的地区方言。

语言目录按能力状态显示：

- 完整出片：文本、配音、字幕和视频链均通过真实生成验证。
- 仅字幕：文本和字幕可生产，配音未通过门禁。
- 配音待配置：目标语言可选，但提交完整出片前必须配置并验证配音。

### 7.4 台词改写和时长

- 本地化台词以源台词语义、说话人、情绪、镜头可说时长和地区口语规则为输入。
- 系统优先压缩或拆分台词，不通过改变视频速度解决明显时长差异。
- 允许小幅调整音频语速和静音，但超出配置阈值时必须退回台词改写。
- 多人对白保留说话顺序、停顿、打断和重叠关系。
- 每次台词修改都触发语义一致性、术语一致性和时长检查。

### 7.5 配音

- 每个角色在一个本地化版本内固定音色。
- 音色映射记录目标语言、地区、年龄、性格、情绪和供应商能力。
- 只有使用目标 Key 完成真实配音生成、等待成功终态且验证音频文件可读取的音色才能标记为可生产。
- 声音克隆只有在供应商能力、用户授权和真实生成验证全部满足时才出现。

### 7.6 字幕

- 字幕以说话人和时间码为基础，可在视频编辑步骤逐条修改。
- 自动检查每行长度、行数、阅读速度、安全区、标点、数字单位、字幕重叠和 RTL 方向。
- 支持烧录字幕和可关闭字幕两种成片版本。
- 导出格式为 SRT 和 VTT；剪映导出包含可编辑字幕轨。

## 8. 系统架构

### 8.1 边界

新增独立转绘编排层，负责源视频分析、本地化版本、资产审核、镜头任务和成片版本。编排层不复制已有生成能力，而是调用现有任务、资产、视频、音频、字幕、合并和计费服务。

### 8.2 前端模块

| 模块 | 职责 |
| --- | --- |
| `RedrawProjectList` | 项目和作品列表、创建入口、状态汇总。 |
| `RedrawWorkspace` | 四步导航、作品状态、版本和恢复。 |
| `RedrawSourceStep` | 上传、语言、地区、风格、画幅和分析报价。 |
| `RedrawAssetStep` | 角色、场景、物品、音色和审核门禁。 |
| `RedrawShotStep` | 批次、分镜、提示词、原片对照和生成队列。 |
| `RedrawEditStep` | 成片预览、轻量时间线、字幕、配音和导出。 |

模块名称用于界定职责，不要求把全部子组件塞入单个文件。实现应遵循现有 Vue 3、Element Plus 和 API 模块模式。

### 8.3 后端模块

| 模块 | 职责 |
| --- | --- |
| `redrawRoutes` | 鉴权、输入校验、响应和幂等入口。 |
| `redrawService` | 项目、作品、版本、资产和分镜业务规则。 |
| `redrawOrchestrator` | 分析、资产生成、镜头生成、配音、字幕和合成编排。 |
| `localizationService` | 事实锁定、术语、人名、台词和文化映射。 |
| 现有任务服务 | 长任务状态、进度、重启恢复和失败原因。 |
| 现有计费服务 | 报价、冻结、结算和释放。 |

### 8.4 模型能力门禁

转绘编排层按能力选择模型，不在业务代码中写死供应商：

| 能力 | 用途 | 生产门禁 |
| --- | --- | --- |
| `video_understanding` | 源片拆镜、角色识别、对白与屏幕文字提取、动作和事实分析。 | 使用目标 Key 完成真实源片分析，结果包含可回读时间码、说话人和事实层。 |
| `text_localization` | 台词、术语、人名和文化表达本地化。 | 真实生成目标语言版本并通过结构、事实和语言检查。 |
| `image_generation` | 角色三视图、场景和物品本地化资产。 | 真实生成并验证图片文件可读取。 |
| `video_generation` | 生成单个本地化分镜视频。 | 真实生成并验证视频文件、时长和分辨率。 |
| `tts` | 角色级外语配音。 | 真实生成并验证音频文件、语言和时长。 |

模型列表或只读连接测试不能满足生产门禁。某项必需能力没有通过验证时，工作台必须在提交前显示明确阻塞，不能退化为模拟任务。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/redraw/projects` | 列出当前用户可访问的转绘项目。 |
| `GET` | `/redraw/style-presets` | 按大类返回通过真实生成门禁的风格预设。 |

| `GET` | `/redraw/projects/:id` | 读取项目和作品摘要。 |
| `POST` | `/redraw/projects/:id/works` | 上传或关联源片并创建作品。 |
| `GET` | `/redraw/works/:id` | 读取四步工作台完整状态。 |
| `POST` | `/redraw/works/:id/analyze` | 创建源片分析任务。 |
| `POST` | `/redraw/works/:id/versions` | 从已确认事实层创建新本地化版本。 |
| `PUT` | `/redraw/assets/:id` | 更新资产名称、描述、提示词或音色。 |
| `POST` | `/redraw/assets/:id/generate` | 生成单个资产版本。 |

成功响应至少包含：

- `success`。
- `project_id` 和 `work_id`。
- `version`。
- `task_id`，同步操作除外。
- `status` 和 `current_step`。
- `billing.held`、`billing.charged`、`billing.released`。
- `artifacts`。
- `updated_at`。

前端只在后端返回 `success: true` 且相应任务或产物可回读时推进步骤。HTTP 200 但缺少任务或产物标识视为失败。

## 11. 状态机与恢复

### 11.1 作品状态

`draft → analyzing → asset_review → ready_to_generate → generating → composing → completed`

任一运行状态可以进入 `failed`。失败后根据失败层级恢复到最近的可继续状态，不回退或删除已完成产物。

### 11.2 下级状态

资产、分镜、配音、字幕和导出分别维护自己的状态。作品状态由后端根据下级真实状态汇总，前端不得自行推断完成。

### 11.3 重启恢复

- 服务启动时扫描运行中转绘任务。
- 有供应商任务 ID 时回读供应商状态。
- 供应商仍运行时恢复轮询。
- 供应商成功时验证结果文件可读取，再写入成功终态。
- 供应商明确失败时写入失败终态并释放未消费积分。
- 无法确定的任务进入 `needs_attention`，不得自动重复提交付费生成。

### 11.4 并发和版本保护

- 分镜更新、资产审核和合成使用版本号或 `updated_at` 做乐观并发控制。
- 批量生成固定使用提交时的版本快照。
- 用户编辑已提交版本时创建新版本，不能改变运行中任务的输入。
- 导入短剧工厂必须指定转绘版本和成片版本。

## 12. 计费合同

### 12.1 报价

- 服务端按模型、时长、清晰度、数量和操作类型计算报价。
- 报价返回定价快照和有效期。
- 所有生成按钮显示「本次预计扣除 X 积分」。未定价时显示「积分待管理员配置」并禁用按钮。

### 12.2 冻结和结算

- 提交时按幂等键冻结报价积分。
- 成功后按实际任务结算。
- 失败、取消或供应商拒绝时释放未消费积分。
- 重试创建新尝试，但不能对同一供应商任务重复冻结或结算。

### 12.3 前端展示

- 任务卡片显示预计、冻结、已扣和已退。
- 余额变化以后端账本为准。
- 批量生成显示总报价和分镜明细。

## 13. 错误处理

| 场景 | 行为 |
| --- | --- |
| 上传校验失败 | 不创建分析任务；显示具体文件和原因。 |
| 源片分析失败 | 保留源片和失败尝试；允许新建分析尝试。 |
| 事实一致性失败 | 阻止资产审核完成；标出冲突事实和受影响镜头。 |
| 资产生成失败 | 只重试该资产；释放未消费积分。 |
| 去人净景失败 | 保留源场景和人物遮罩；只重试净景版本并释放未消费积分。 |
| 单镜生成失败 | 保留其他镜头；只重试失败镜头。 |
| 配音时长失败 | 退回台词改写，不自动加速视频。 |
| 字幕排版失败 | 阻止成片发布，但允许继续编辑字幕。 |
| 视频合并失败 | 保留所有镜头、音频和字幕，允许重新拼接。 |
| 服务重启 | 回读任务并恢复，不重复提交付费生成。 |
| 积分不足 | 不创建供应商任务；返回缺口和当前余额。 |

## 14. 权限与数据安全

- 所有记录包含 `tenant_id` 和 `user_id`，并通过现有资源归属中间件校验。
- 用户只能访问自己被授权的项目、源片、任务、账单和导出。
- 源视频、配音和字幕使用受控资产 URL，不返回服务器绝对路径。
- 日志不得记录 API Key、完整请求头、签名 URL 或用户原始凭证。
- 上传文件经过 MIME、文件头、大小、时长和解压路径校验，防止 ZIP 路径穿越。
- 删除采用软删除和资产引用检查；运行中任务和已结算账单不得物理删除。

## 15. 可观测性

每个任务日志和指标包含：

- `tenant_id`、`user_id`、`project_id`、`work_id`、`version`。
- `asset_id` 或 `shot_id`。
- `task_id`、供应商、模型和供应商任务 ID 的脱敏标识。
- 当前阶段、进度、耗时、重试次数和终态。
- 预计、冻结、结算和释放积分。

需要提供以下指标：

- 上传和分析成功率。
- 资产审核前平均重绘次数。
- 单镜生成成功率和 P50/P95 耗时。
- 配音时长合格率和字幕质检失败率。
- 合并成功率。
- 任务恢复数量和 `needs_attention` 数量。
- 冻结、结算和释放积分差异。

## 16. 测试与验收

### 16.1 自动化测试

- 数据迁移、唯一约束和租户隔离测试。
- 风格预设分类、排序、版本快照、模型兼容性和 `verified` 门禁测试。
- 事实层与本地化版本不可覆盖测试。
- 资产审核门禁测试。
- 单镜和批量生成幂等测试。
- 报价、冻结、结算和释放测试。
- 任务重启恢复和供应商回读测试。
- 合并失败保留产物测试。
- API 成功字段和错误字段合同测试。
- 前端路由恢复、步骤门禁、状态展示和积分文案测试。

### 16.2 真实同链验收

必须使用一段用户授权的真实中国短剧完成：

1. 上传源片。
2. 逐类浏览风格卡片，选择一个通过门禁的预设，再选择目标语言和地区。
3. 等待真实源片分析完成。
4. 检查角色、场景、物品、台词和分镜时间码。
5. 真实生成本地化资产并人工确认。
6. 真实生成全部分镜视频、外语配音和字幕。
7. 合并成片并验证文件可读取。
8. 在浏览器中验证原片对比、字幕开关、外语配音、失败重试和刷新恢复。
9. 下载 MP4、SRT/VTT，并在任务指定的剪映桌面版本中导入工程归档。
10. 检查积分冻结、结算和释放与任务终态一致。

剪映导出还必须在任务指定的剪映桌面版本中实际导入并打开，验证镜头顺序、音频、字幕和时间码。只生成或下载归档文件不能视为通过。

验收证据必须记录：

- 源片资产 ID 和内容指纹，不记录用户隐私内容。
- 转绘项目、作品、本地化版本和任务 ID。
- 使用的目标语言、地区、供应商和模型。
- 每个资产、分镜、音频、字幕和成片的可读性结果。
- 浏览器步骤、控制台错误、后端错误日志和健康检查结果。
- 失败注入和恢复结果。
- 不含密钥的积分账本摘要。

### 16.3 完成判定

只有真实同链全部通过，功能才能标记为产品完成。以下情况不能替代真实验收：

- 静态页面或模拟接口。
- 仅模型列表和只读连接测试。
- 单元测试、集成测试或构建通过。
- 历史报告、固定夹具或旧产物。
- 只生成角色图、单个镜头或字幕而没有完成同一作品成片。

## 17. 发布约束

- 实现和验证在独立 worktree 完成。
- 每个外部生成模型必须先用目标 Key 完成真实生成，等待成功终态并验证结果文件可读取，才允许进入生产目录。
- 制作生产候选前必须通过 SSH 读取实时 `/opt/moli-drama/current`，并从实时 release 克隆候选。
- 候选必须保留 `canvas-credit-callout-v1` 受保护合同。
- 候选构建后执行共享审计器。
- 生产切换只能使用共享保护激活脚本，且必须通过部署锁、CAS、备份、活动任务、健康、日志和 AI 音乐进程隔离检查。
- 本功能失败不得影响现有短剧工厂、画布、剧本分析和 AI 音乐服务。

## 18. 已锁定决策

- 采用独立四步转绘工作台，不扩展现有 `FilmCreate.vue` 承载完整流程。
- 功能、页面结构、步骤顺序、交互反馈和可恢复状态按竞品级 `1:1` 对齐。
- 4 个风格大类、横向预览卡片和已调研到的真人写实风格预设完整纳入首版。
- 本地化策略为忠实本地化。
- 资产审核为批量视频生成前的强制门禁。
- 目标语言同时驱动台词、配音、字幕和视觉文化适配。
- 语言可见不等于配音可生产；完整出片状态由真实生成证据决定。
- 转绘版本和原短剧相互隔离，只有明确导入操作才写入短剧工厂。
- 所有付费生成必须具备报价、冻结、结算、释放和幂等合同。
- 所有完成声明必须有真实浏览器、真实模型、后端回读和产物可读取证据。
