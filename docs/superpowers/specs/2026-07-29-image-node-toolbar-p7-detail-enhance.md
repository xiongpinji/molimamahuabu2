# 图片节点工具栏 P7：细节纹理增强实施约束

## 范围

- 本包只实现“细节纹理增强”。
- 不实现核验、侵权检测、版权判断，也不顺带开放灯光、姿势、角度、全景、联想或对口型。
- 只修改图片工具服务、图片工具路由、图片节点工具栏及其直接测试和验证报告。
- 原素材永不覆盖；成功后创建新的派生素材和异步任务记录。

## 实现选择

- 复用 P4 已完成许可证、二进制、运行库和模型哈希审计的 Real-ESRGAN `realesrgan-x4plus` 成品引擎。
- 不新增运行时依赖，不下载新权重，不复制第三方私有接口。
- 处理链固定为：
  1. 使用 Real-ESRGAN 做 2x 超分；
  2. 使用项目已有 Sharp 以 Lanczos3 回落到源图尺寸；
  3. 按“自然 / 标准 / 强烈”三档执行受限锐化；
  4. 输出新的 PNG 派生素材。
- 与“高清增强”的边界：
  - 高清增强输出 2x / 3x / 4x 新尺寸；
  - 细节纹理增强保持源图宽高不变。

## 安全与隔离

- 只有 Real-ESRGAN 能力探针通过时才公布“细节纹理增强”可用。
- 继续复用 P4 的绝对路径、包目录、运行库、模型哈希和并发门禁。
- 中间 2x 文件和最终派生文件均只能写入已验证的派生目录；失败时统一清理。
- 最终文件必须是可解码 PNG，尺寸与源图完全一致，文件非空且不超过现有输出上限。
- Real-ESRGAN 原始 stderr、命令路径和本地目录不返回前端或任务错误。
- 公开平台仍由现有图片工具总门禁控制；本包不扩展计费或审计语义。

## 验收标准

1. 未配置或未通过审计的 Real-ESRGAN 时，“细节纹理增强”保持不可用。
2. 能力通过时，前端只提交 `preset=natural|balanced|strong`。
3. 成功结果：
   - 新素材 `operation=detail_enhance`；
   - `engine=realesrgan-ncnn-vulkan+sharp`；
   - metadata 记录模型、固定超分倍率和锐化预设；
   - 输出宽高等于源图；
   - 原素材仍存在且未覆盖。
4. 非法预设、模型失败、错误尺寸或不可解码产物均失败写回，不留下中间文件或派生素材。
5. 后端目标测试、后端全量测试、前端目标测试、前端全量测试、前端构建和 `git diff --check` 全部通过。
6. 使用隔离端口完成真实本地浏览器、数据库、文件和刷新回读验证。
7. 审计通过前不提交；全功能总审计完成前不推送、不创建 PR、不部署。
