# 灵境 Seedance 2.0 Fast 接入设计

日期：2026-08-10

状态：用户已批准，等待实施

供应商：`https://seed.alimyun.xyz`

## 目标

恢复已经存在但目前停用的灵境视频渠道，并让首页、画布、短剧工厂和管理员后台使用同一份能力目录。公开模型键继续使用 `lingjing-video-v1`，供应商上游模型键使用当前账号实际返回的 `relay`，避免历史任务、计费记录和前端草稿因模型重命名失效。

## 已确认事实

- 生产配置 ID 3 指向 `https://seed.alimyun.xyz/api/open/v1`，目前 `is_active=0`、`is_default=0`。
- 使用生产现有 Key 只读调用 `GET /api/open/v1/models` 成功，当前账号只返回一个模型：
  - `id=relay`
  - `display_name=Seedance 2.0 fast【9参】不卡脸`
  - `allowed_durations=[4,5,6,8,10,11,15]`
  - `allowed_ratios=[16:9,9:16,1:1,4:3,3:4,21:9]`
  - `resolutions=[]`
- 供应商公开 OpenAPI 定义：
  - `POST /api/open/v1/uploads` 上传参考图并返回 path；
  - `POST /api/open/v1/videos` 创建任务；
  - `GET /api/open/v1/videos/{task_id}` 查询任务；
  - `GET /api/open/v1/videos/{task_id}/download` 下载成品；
  - 创建字段包括 `model_key`、`reference_images`、`request_id`；
  - 通用接口虽定义视频和音频上传，但当前 `relay` 模型目录没有声明视频参考、音频参考或可控的同步音频开关；供应商生成的 MP4 可以自带音轨，成品音轨不等于音频参考能力。
- 当前本地适配仍把 `lingjing-video-v1` 直接发给供应商、写死 12 张参考图、没有 `request_id`，并保留旧 `/content` 下载路径。
- 生产只读复核发现唯一旧配置仍是停用的 `provider=xai/api_protocol=xai`；基础价格为 69 积分/秒、成本 0.18 元/秒，并残留 480P/720P 两条分档，均不符合当前无分辨率合同。
- 供应商 `GET /api/public/settings` 当前公开 `relay.price_per_second=1.0`、`rmb_per_credit=0.17`，因此审核成本为 0.17 元/秒；本站按 875 积分/元向上取整为 149 积分/秒。

供应商文档：

- Swagger：<https://seed.alimyun.xyz/docs>
- OpenAPI：<https://seed.alimyun.xyz/openapi.json>

## 设计

### 模型身份

三层身份必须分离：

1. 本站稳定模型键：`lingjing-video-v1`；
2. 管理员展示名：可编辑，默认“灵境 Seedance 2.0 Fast（9 图参考）”；
3. 供应商上游模型键：`relay`。

历史记录、草稿和价格继续绑定本站稳定模型键。供应商请求只能使用配置中经过验证的上游模型键，不能再依赖模型名称特判。

### 独立协议适配

新增明确的 `lingjing_open` 协议边界，职责仅包括：

- 读取 `/models` 并解析当前 Key 可用的模型合同；
- 上传图片参考素材；
- 使用 `model_key=relay` 创建视频任务；
- 为每次创建生成不可复用的 `request_id`；
- 轮询整数任务 ID；
- 优先消费任务响应中的视频 URL，必要时使用鉴权下载端点；
- 把供应商失败状态和错误信息映射为站内终态，触发现有退款链。

不得继续用 `xai`、`aihubcc` 或模型名称特判隐式路由该供应商。

### 能力矩阵

首版只开放已由供应商目录确认且能真实验证的能力：

- 图片参考：最多 9 张；
- 视频参考：不开放；
- 音频参考：不开放；
- 首尾帧：不单独开放，图片统一作为有序多图参考；
- 同步音频：不开放；
- 成品音轨：允许供应商 MP4 自带音轨，但不得据此开放音频参考或同步音频输入；
- 时长：4、5、6、8、10、11、15 秒；
- 比例：16:9、9:16、1:1、4:3、3:4、21:9；
- 分辨率：供应商目录返回空数组，前端不展示分辨率选择，也不向供应商强制发送分辨率；
- 数量：1。

若 `/models` 后续变化，只能先记录为待验证能力，不能自动扩大生产开放范围。

### 前端与全站同步

首页、画布、短剧工厂和管理员后台继续只读本站统一 `/canvas/model-catalog`。目录条目包含本站模型键、展示名、公开备注、能力矩阵和计费信息。前端不得自行写死 `relay`、9 张参考图或时长列表。

模型切换时必须原子校正不可用参数并保存；历史草稿带旧非法参数时，提交前给出明确错误，不静默改成另一种付费请求。

### 计费与证据

供应商 `/models` 的 `price_per_second=1.0` 必须与公开设置中的 `rmb_per_credit=0.17` 同时绑定，不能只凭模型目录推断人民币成本。首次启用事务将唯一旧模型精确迁移为 0.17 元/秒、149 积分/秒，并删除该模型旧 480P/720P 分档；回执保存配置、基础价格和分档的完整旧值，可原子回滚。其他模型、价格、用户、任务和积分记录不得改变。

模型重新公开前必须完成一次最低成本验证：

- 4 秒；
- 单张非真人参考图；
- 仅一次创建，不自动重试；
- 保存请求 ID、供应商任务 ID、完整终态、成品 SHA-256、MIME、宽高、时长、可读性和供应商扣费；
- 确认站内预扣、确认或退款账本闭环；
- 证据与配置 ID、上游模型键、协议和候选提交严格绑定。

连接测试和 `/models` 返回不能把配置升级为已验证。

### 安全与发布

- API Key 只在后端读取，不进入前端、日志、证据或 Git；
- 上传素材必须继续执行租户、项目归属和公网下载安全检查；
- `request_id` 防止同一业务任务重复创建供应商任务；
- 未验证、缺价或停用配置不得进入任何前端目录；
- 发布候选必须从部署时最新 `/opt/moli-drama/current` 克隆；
- 必须保留 `canvas-credit-callout-v1`；
- 只允许共享受保护激活脚本完成 CAS 切换。

## 验收标准

1. 合同测试能证明本站模型键与上游 `relay` 分离。
2. 旧 `model=lingjing-video-v1`、12 张参考图、`/content` 下载路径和无 `request_id` 请求均被测试拒绝。
3. 后端、前端定向测试和生产构建通过。
4. 一次 4 秒单图真实任务成功，成品可读取且账单闭环。
5. 首页、画布、短剧工厂和管理员后台显示同一展示名、备注和能力。
6. 缺证据、缺价格、能力漂移或供应商目录不再包含 `relay` 时，全站自动隐藏该模型。
7. 受保护生产切换后健康检查、活动任务、日志、数据库和浏览器实操验收全部通过。

## 非目标

- 本次不恢复真人参考或虚拟人素材流程；该任务线等待供应商反馈。
- 不开放当前账号未声明的视频参考、音频参考、首尾帧或同步音频。
- 不进行多次、长时或高分辨率付费测试。
