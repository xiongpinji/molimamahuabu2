# P13 图片节点全景能力规格

## 目标

在隔离分支补齐图片节点的 `720全景` 与 `生成全景场景`。两项能力复用已经审计的火山引擎 Seedream 参考图适配器，输出新的 2:1 等距柱状全景素材，不覆盖源图片。

本包不增加核验、侵权检测、版权判断，也不改变其他节点或图片工具的行为。

## 能力边界

- `panorama`：将当前图片转换为完整 360° 等距柱状全景，重点保持原图主体、场景线索和视觉风格。
- `panorama_scene`：以当前图片为场景参考生成完整 360° 环境，允许用户补充场景要求。
- 两项能力固定输出 `3840x1920` PNG，metadata 记录 `projection=equirectangular`。
- 两项能力分别使用 `supports_panorama=true`、`supports_panorama_scene=true` 显式声明；一个开关不得误开放另一项。
- 仅允许 `storyboard_image / volcengine / volcengine / doubao-seedream-4-5` 这一已审计组合。
- 未配置、未声明、适配器不匹配或公开平台计费与审计链未接通时，入口保持“未接通”。

## 输入

```json
{
  "assetId": 1,
  "sourceNodeId": "image-node-1",
  "operation": "panorama",
  "parameters": {
    "description": "保持山谷中央的木屋"
  }
}
```

- `description` 可选，必须是字符串，去除首尾空白后最多 300 个字符。
- 后端只从当前租户素材记录解析参考图，不接受调用者提供的本地路径或远程参考图。

## 处理与产物门禁

1. 源图必须是存储根内的 PNG、JPEG 或 WebP。
2. 供应商请求只包含这一张源图，尺寸固定为 `3840x1920`。
3. 提示词明确要求 360° 等距柱状投影、左右边缘无缝、单张连续画面，禁止拼图、文字、水印和前后对比图。
4. 供应商原始返回不得与源文件哈希相同。
5. 返回图片必须是允许格式、像素数不超过现有上限，宽高比与 2:1 偏差不超过 1%。
6. 最终归一化为 `3840x1920` PNG；空文件、超限文件和与源图相同的结果全部失败。
7. 成功后创建新资产并写入任务结果；失败时删除临时文件、保留源图片和旧节点结果。
8. 错误响应与日志不得包含供应商响应正文、密钥、本地路径或用户描述。

## 前端

- 两个入口均打开同一个轻量参数面板，显示固定输出规格与可选补充要求。
- `panorama` 与 `panorama_scene` 分别提交对应 operation。
- 失败重试只持久化 `description`，最大 300 字；刷新后可恢复。

## 验收

- 能力门禁、严格配置、输入校验、供应商失败、同图返回、错误画幅、产物入库和任务状态均有后端测试。
- 前端参数面板与重试持久化有测试。
- 目标测试、前后端全量测试、生产构建、依赖审计和禁区扫描通过。
- 本地浏览器完成成功、失败、刷新回读和源资产哈希不变的同链验证。
- 总功能尚未完成前不推送、不创建 PR、不部署。

## 依据

- 火山引擎 Seedream 官方算子文档：支持参考图生成与自定义输出尺寸。
- 火山引擎图片生成接口文档：生成宽高比不超过 3，像素范围覆盖 `3840x1920`。
