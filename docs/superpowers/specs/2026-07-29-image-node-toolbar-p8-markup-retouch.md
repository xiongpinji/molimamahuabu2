# 图片节点工具栏 P8：标记修图

## 范围

本包只补齐图片节点的“标记修图”，不包含核验、侵权、版权判断，也不改变其他节点和既有图片工具的行为。

## 采用方案

- 交互层：使用浏览器原生 SVG Pointer Events 采集用户笔迹，不引入新的前端运行时依赖。
- 标记图：后端用现有 Sharp 把标准化笔迹合成到原图副本，生成临时 PNG 标记参考图。
- 生成层：复用 P6 已审计的 Seedream 参考图供应商适配器，同时提交原图和标记图。
- 能力门禁：仅当默认参考图模型显式配置 `supports_markup_retouch=true`，且协议为已审计的 Volcengine Seedream 适配器时开放。
- 公开平台：计费与审计链未接通前继续禁用，只允许本地模式使用。

官方依据：

- 火山引擎《Seedream 4.0-5.0 提示词指南》明确说明图像编辑可通过箭头、线框、涂鸦等视觉信号控制区域，并支持多图输入：
  `https://www.volcengine.com/docs/82379/1829186`
- 火山引擎 Seedream 图像生成处理器文档明确支持一张或多张参考图：
  `https://www.volcengine.com/docs/6492/2221472?lang=zh`

## 输入契约

- `instruction`：必填，1 到 500 个字符。
- `strokes`：1 到 16 条。
- 每条笔迹：
  - `color`：只允许后端白名单颜色。
  - `width`：归一化宽度，范围 `0.005` 到 `0.08`。
  - `points`：2 到 128 个归一化坐标点，`x/y` 均在 `[0, 1]`。
- 前后端都执行白名单和数量限制；后端是最终信任边界。

## 执行链

1. 校验素材归属、格式、像素上限和标记参数。
2. 在项目派生目录生成临时标记 PNG，不覆盖原图。
3. 向已审计供应商提交：
   - 图一：未修改原图；
   - 图二：带标记的原图副本；
   - 文本：仅修改标记区域、清除输出中的标记、保留其他内容。
4. 下载结果并执行 URL、大小、MIME、像素和画幅校验。
5. 用 Lanczos3 规范为原图尺寸，生成新的 PNG 派生素材。
6. 删除临时标记图和下载中间文件。
7. 成功写回任务、素材与历史；失败写回统一错误，保留节点旧图。

## 成功标准

- 能力未显式声明、适配器未审计或公开平台模式下，入口保持“未接通”。
- 前端可画线、撤销、清空、填写指令并只提交受限参数。
- 真实供应商收到两张参考图，标记图不离开项目允许目录之外。
- 结果为独立 PNG 素材，宽高与源图一致，源图字节不变。
- 供应商错误、内部路径、命令和凭据不返回前端或任务错误。
- 临时标记图、中间文件和失败结果无残留。
- 专项测试、完整回归、构建、安全审计、真实浏览器、数据库回读和文件产物验证全部通过。
- 全部非核验功能完成并总审计前不推送、不创建 PR、不部署。

## 取舍

- 不把笔迹截图直接从浏览器上传，避免远程图片导致 Canvas 污染，也避免无界 Base64 请求体。
- 不开放任意颜色、任意 SVG 或任意文件路径，防止注入和资源滥用。
- 不宣称本包支持所有图片供应商；当前只审计 Volcengine Seedream。
- 不做局部像素级蒙版推理；标记图是供应商官方文档支持的视觉信号输入。
