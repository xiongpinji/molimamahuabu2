# 图片节点工具栏 P12：电影级光影校正

## 目标

在隔离分支为图片节点接入真实的“电影级光影校正”能力，复用已经审计的参考图图片供应商适配器。能力只在默认图片模型显式声明支持时开放；未配置、未声明、未审计或公开平台计费链未接通时继续显示为不可用。

## 范围与边界

- 只处理独立画布中的图片节点，不修改其他节点类型。
- 当前图片只作为参考图；成功后生成新的同尺寸素材，原素材文件保持不变。
- 不把光影校正归入 3D 导演台，不写入导演台时间线或场景对象。
- 不自动替换源素材记录；仅在完整处理与产物校验成功后，由现有图片节点结果链切换节点 URL。
- 不增加核验、侵权检测、版权判断或相邻能力。
- 不新增供应商密钥、默认配置或静默回退；真实可用性由现有 AI 配置决定。

## 供应商开放条件

同时满足以下条件才公布 `cinematic_relight.available=true`：

1. 默认 `storyboard_image` 图片配置处于启用状态；
2. `settings.supports_cinematic_relight === true`；
3. 协议为 `volcengine`，模型名属于已审计的 Seedream/豆包适配器；
4. `base_url` 与 `api_key` 完整；
5. 当前不是尚未接通计费与审计链的公开平台模式。

## 用户输入

- 光影预设：`cinematic`、`golden_hour`、`moonlight`、`studio_soft`、`high_contrast`；
- 强度：整数 `1..5`，默认 `3`；
- 补充要求：可选，去除首尾空白后最长 300 字。

服务端必须拒绝未知预设、越界/非整数强度、超长补充要求和空白控制字符绕过。

## 处理与产物契约

1. 读取并验证源图片格式、尺寸、像素上限；
2. 通过参考图供应商提交单张源图、同尺寸目标和受控提示词；
3. 下载结果到当前项目派生目录；
4. 校验结果格式、像素上限、宽高比；
5. 将结果归一化为与源图完全相同的宽高并输出 PNG；
6. 拒绝空文件、超限文件以及与源图哈希完全相同的产物；
7. 记录引擎、协议/模型、预设、强度、补充要求和 `preserveDimensions=true`；
8. 失败时清理临时文件、写回任务失败状态，且不泄露上游错误或密钥。

## 前端交互

- 入口继续位于“设定”菜单。
- 仅当后端能力为可用时打开编辑器。
- 编辑器明确说明“供应商生成新素材，原图保持不变”。
- 成功沿用现有图片工具结果链；失败保留旧图和原参数，允许原样重试。

## 验收标准

- 能力开关、未声明模型、未审计模型和公开平台模式均有自动化测试。
- 成功链验证真实参考图请求、同尺寸新素材、原图哈希不变、元数据与任务状态。
- 失败链验证无效输入、上游失败、损坏/不合规产物、清理和错误脱敏。
- 前端测试覆盖编辑器字段、参数提交、结果切换和重试保持。
- 目标测试、全量前后端测试、前端构建、依赖审计、禁用词扫描与浏览器隔离验证全部通过后，才能提交该项。
