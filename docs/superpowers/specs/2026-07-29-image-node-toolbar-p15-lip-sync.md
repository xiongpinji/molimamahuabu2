# 图片节点工具栏 P15：对口型实施规格

> 状态：2026-07-29 用户明确暂缓。本规格仅保留前期调研记录，当前迭代不实施、
> 不验收、不进入发布完成门槛；`lip_sync` 继续保持不可用。

## 目标

为图片节点接入真实的“图片 + 项目音频 → 对口型 MP4”能力。源图片和源音频保持不变，成功结果作为视频派生资产写入，并在画布创建独立视频结果节点。

本包不包含核验、侵权检测或版权判断。

## 分包

### P15-A：来源与运行门控

- 只接受官方 `TMElyralab/MuseTalk` 源码和官方发布的模型权重。
- 固定并记录源码提交、许可证文件哈希和依赖清单哈希。
- 排除官方明确禁止商业使用的 Wav2Lip 开源版。
- 没有 NVIDIA CUDA GPU、FFmpeg、完整模型权重或可复现运行环境时，`lip_sync` 必须保持不可用。
- 本阶段不修改图片节点、视频节点或既有生成链的运行行为。

### P15-B：轻量服务器商用 API 处理链

- 输入必须是当前项目可访问的图片资产和音频资产。
- 后端校验资产归属、类型、本地路径和允许的存储根目录。
- 线上轻量服务器不运行 GPU 模型，使用 HeyGen 官方 `POST /v3/videos`
  Image-to-Video 接口提交图片和现成音频。
- API 密钥只从服务端环境读取，不返回前端、不写入任务结果或日志。
- 图片和音频通过官方素材上传接口提交；不得为了调用供应商把项目素材长期公开。
- 使用幂等键提交任务，保存供应商任务 ID，并通过官方状态接口异步轮询。
- 能力只有在密钥配置、连接探测、计费确认和真实产物验证全部通过后开放。
- 输出必须是包含视频流和音频流的 MP4；使用 FFprobe 校验时长、编码流和可读取性。
- 任务成功后创建 `type=video` 的派生资产，元数据记录源图片、源音频、供应商、
  API 版本、供应商任务 ID、本地任务 ID 和处理参数。
- 前端不得用视频 URL 覆盖源图片节点；应创建独立视频结果节点并连接来源。
- 失败时保留源节点与源资产，写回可见错误并允许重试。

## 许可证决策

### 线上采用候选：HeyGen API

- 官方 v3 Videos API 支持从任意人物图片创建视频。
- 支持 `audio_url` 或已上传的 `audio_asset_id`，无需由供应商生成语音。
- 返回异步 `video_id`，可轮询状态并在完成后下载 MP4。
- 需要单独购买 API 服务并配置服务端密钥。
- 图片和音频会发送给第三方，产品执行前必须明确提示并取得用户确认。

### 保留的离线候选：MuseTalk

- 官方源码许可证：MIT。
- 官方 README 声明代码和训练模型可用于商业用途。
- 其他依赖和模型仍需分别遵守其许可证。
- 审计固定提交：`0a89dec45a0192b824e3cf4daf96c239440c5ed8`。
- `LICENSE` SHA-256：`858C5FDC07B8D71E1C88B64337BBC2C32A70A621733AB19809140EC9E19E6904`。
- `requirements.txt` SHA-256：`18D19F2FB05E2330DF94E3C6B216FB6DA952945ABF08C4E6ECF74E7CF39908BD`。

### 排除：Wav2Lip 开源版

官方仓库明确限定个人、研究和非商业用途，不能进入本项目的商业运行链。

## P15-B 开工门槛

以下条件必须全部满足：

1. 取得专用于隔离验证环境的 HeyGen API 密钥，不复用生产密钥。
2. 明确套餐、单次费用、并发限制和供应商数据处理条款。
3. 使用自有或明确授权的测试图片与音频。
4. 完成图片、音频上传，视频提交、轮询、下载及失败响应的真实接口验证。
5. 下载后使用 FFprobe 验证 MP4 的视频流、音频流、时长和可读取性。
6. 完成第三方上传前确认、最小化日志、临时素材清理和密钥泄漏审计。

## 完成定义

只有以下条件全部成立时，`lip_sync` 才能从不可用切换为可用：

- `implemented`
- `backend_readback`
- `artifact_verified`
- `failure_writeback`
- `real_browser_verified`
- `license_audited`

静态 UI、固定 MP4、普通图生视频、测试桩或只有适配接口均不计为完成。
