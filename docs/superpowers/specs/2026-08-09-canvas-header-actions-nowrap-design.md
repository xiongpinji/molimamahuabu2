# 画布顶部操作区单行布局设计

## 目标

修复 `/canvas` 顶部“兑换积分”掉到第二行的问题，同时保留右上角“可用积分 / 个人中心”浮动卡片，并兼容中等宽度与手机宽度。

## 根因

- `PlatformHeader` 的操作区设置了 `flex-wrap: wrap`，允许按钮换行。
- 公共平台登录态固定预留 `340px` 给浮动积分卡；在画布页同时展示素材库、导入、新建、充值和兑换入口时，可用宽度不足。

## 方案

采用共享顶部栏的最小 CSS 修复：

1. 操作区改为单行且不收缩，避免任一按钮掉到第二行。
2. 将固定 `340px` 改为随视口宽度递减的避让空间：窄桌面最多预留 `240px`，宽桌面在顶部栏自然不会覆盖积分卡时降为 `0px`。
3. 中等宽度隐藏充值、兑换等通用按钮的文字，仅保留图标与 `title`；手机端继续使用现有积分卡第二行布局。

不移动积分卡、不改导航结构、不修改画布业务逻辑。

## 验收

- 自动化回归测试约束操作区 `nowrap`、动态避让和中等宽度收缩规则。
- 前端完整测试与生产构建通过。
- 独立本地服务在桌面与窄屏下检查：按钮不换行、不与积分卡重叠、核心入口仍可见。
