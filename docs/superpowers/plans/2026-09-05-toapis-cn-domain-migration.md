# ToAPIs `.cn` 域名迁移

## 目标

把 ToAPIs Seedance 与 Wan 3.0 的唯一官方入口从 `https://toapis.xyz` 迁移为 `https://toapis.cn`，并保持生产路由暂停，直到使用目标 Key 完成新的真实生成验证且结果文件可读取。

## 成功标准

- 客户端只接受精确 HTTPS 主机 `toapis.cn`，允许空路径或 `/v1`，拒绝旧 `.xyz`、子域名、端口、用户信息、查询和片段。
- 管理后台预设、帮助文字、验证脚本和证据合同全部绑定 `https://toapis.cn`。
- 旧域名生成的验证证据不再满足新域名发布门禁。
- 生产配置 `#16`、`#27`、`#28` 更新 `base_url`；按现有连接变更规则同步把 `verification_status` 置为 `unverified`、清空验证时间并作废旧金丝雀证据。模型 ID、密钥和价格不变，`canary_paused` 保持 `1`。
- 本机与生产服务器均能解析 `toapis.cn`，主页返回 `200`，未带令牌访问 `/v1/models` 返回预期的 `401`。
- 不在本任务中发起付费生成，也不解除 ToAPIs 路由暂停。

## 验证顺序

1. 先修改测试并确认因仍指向 `.xyz` 而失败。
2. 最小修改客户端、管理员预设和验证工具，运行相关回归。
3. 在线备份生产数据库并校验备份，随后迁移三条生产配置；连接证据自动失效，路由继续暂停且不进入公开画布目录。
4. 后续单独确认付费实测的模型、参数、预计费用和提交次数；只有新域名的真实生成、终态轮询和成品检查全部通过，才生成新的发布证据。
5. 从操作时生产 `current` 构建精确候选，执行共享门禁；共享门禁升级作为独立安全变更复核，全部通过后才允许激活和考虑解除暂停。
