# 视频节点工具栏功能验收合同

## 范围与依据

- 目标：在已生成且已入库的视频节点上提供与 LibLib 视频工具栏一致的工作流，不做只有按钮或提示框的静态仿制。
- 页面级证据来自 2026-08-01 登录态 `liblib.tv/canvas` 实测。
- 不复制 LibLib 私有代码、接口、图标路径或供应商实现；后端使用项目现有资产、异步任务、FFmpeg/ffprobe 和已配置模型能力。
- 处理结果必须生成新的项目素材和新的画布结果节点，保留源视频，不原地覆盖。

## 已实测的参考行为

1. `裁剪` 进入视频画面上的可拖拽、可缩放矩形选区，显示输出像素尺寸；确认后生成新视频。
2. `高清` 新增独立处理节点，提供 1080P、2K、4K、补帧模式和慢放倍数；不是简单修改播放器尺寸。
3. `解析` 点击后立即启动异步任务；完成后新增“视频故事”节点，以表格返回镜号、起止时间、时长、画面/叙事/镜头信息和关键帧。
4. `智能去字幕` 在参考视频上因能力条件不满足而禁用；本项目只有在真实处理引擎可用时才允许点击。
5. `音频分离` 和 `画面编辑` 是下拉工具组。
6. 下载必须下载实际视频文件；全屏必须打开当前视频的真实全屏预览。

## 本项目的可交付解释

“1:1”指入口、状态、处理任务、派生素材、结果节点、失败与重试闭环一致，不冒充 LibLib 的 Topazlabs 或其他私有模型。各项能力的真实引擎如下：

| 工具 | 真实引擎 | 输出 |
| --- | --- | --- |
| 裁剪 | FFmpeg `crop` | 新视频素材 + 新视频节点 |
| 高清 | FFmpeg Lanczos 缩放、锐化，可选帧插值/慢放 | 1080P/2K/4K 新视频素材 + 新视频节点 |
| 解析 | ffprobe 元数据 + FFmpeg 场景切分和关键帧提取 | 结构化视频故事结果 + 关键帧素材 |
| 智能去字幕 | FFmpeg `delogo`，由用户框选字幕带，按真实像素处理 | 新视频素材 + 新视频节点 |
| 音频分离 | FFmpeg 音轨提取或移除 | 新音频素材/节点或静音视频素材/节点 |
| 画面编辑 | FFmpeg 旋转、镜像、速度、画面调节 | 新视频素材 + 新视频节点 |
| 下载 | 浏览器下载当前结果 URL | 实际媒体文件 |
| 全屏 | 原生全屏/全屏预览 | 当前视频播放器 |

说明：字幕处理是“选区去除”，不声称具有未经接入的 OCR 自动检测；UI 必须明确这一点。解析首版以真实场景切分、时间轴和关键帧为证据，不伪造 AI 画面描述；只有配置了可验证的视觉模型后才显示 AI 描述字段。

## 强制验收

1. 没有本地项目视频素材时工具栏不出现，不能把公网 URL 直接交给 FFmpeg。
2. 后端校验素材归属、视频类型、真实路径和路径边界，拒绝跨项目/跨租户访问。
3. 每次处理创建 `async_tasks`，返回任务 ID；前端轮询并可在刷新后恢复。
4. 成功任务写入 `assets`，返回 `resultAssetId`、`resultUrl`、媒体尺寸/时长；失败任务写入明确错误，不覆盖源节点。
5. 视频输出可由 ffprobe 打开；裁剪尺寸为偶数；音频提取结果含音频流；静音结果不含音频流。
6. 前端完成后创建新的结果节点并保留源节点，处理历史记录任务和结果素材。
7. 下载和全屏不依赖后端模拟；按钮有可访问名称。
8. 定向测试先红后绿，随后通过后端全量测试、前端测试、生产构建和浏览器交互回归。
9. 能力接口按服务器上的 FFmpeg/ffprobe 实况返回可用性；前端在能力未加载或不可用时禁用处理入口并显示原因。
10. 单进程最多同时执行 2 个视频处理任务；源视频限制为 30 分钟、8K 像素量，ffprobe、关键帧和 FFmpeg 主任务均有超时保护。
11. 解析中途失败必须同时回滚本次已创建的关键帧文件和素材记录，不能留下半成品。

## 非目标

- 不购买、内置或冒充 Topazlabs。
- 不在未审计许可证、模型文件和哈希的情况下引入第三方 AI 二进制。
- 不修改 AccountAdmin、TenantConsole、BillingAdmin、AdminWorkspace、AI 音乐或现有图片工具行为。
- 不在 LibLib 继续触发付费生成。
