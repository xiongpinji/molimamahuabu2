# 画布项目中心第二阶段：搜索与完整复制

## 目标

- 画布项目中心可按标题或描述搜索当前租户的画布项目。
- 用户可一键复制画布项目，副本使用新的项目及关联数据 ID。
- 副本保留完整画布元数据、角色、场景、道具、剧集、分镜及已有媒体。
- 复制前校验当前用户/租户对源项目的访问权，副本归属当前租户。

## 实现约束

- 继续复用唯一的 `DramaCanvas.vue`，不复制画布引擎。
- 复用现有项目导出/导入服务完成深复制和关联 ID 重映射。
- 不复制正在执行的异步任务，不触发模型调用和积分计费。
- 本阶段不加入文件夹、版本历史和多人实时协作。

## 验收标准

1. 搜索请求同时携带 `keyword` 与当前 `project_type`。
2. 复制后源项目与副本 ID 不同，画布布局和核心关联数据保持一致。
3. 其他租户无法复制源项目。
4. 前端复制按钮具有明确的无障碍名称和加载状态。
5. 聚焦测试、前后端全量测试、前端构建和浏览器验收均通过。
