# 3D 导演台验证资产

`khronos-simple-skin.gltf` 是 3D 导演台自动化验收使用的最小静态资产，仅用于验证：

- 可见蒙皮网格加载；
- 骨骼与内置动画被 `GLTFLoader` 识别；
- 模型 URL 与缩放参数可以保存并在刷新后恢复。

它不是产品默认角色，也不是专业角色库，不代表 VRM 语义、动作重定向或 IK 能力。
