# 实现风险

## 高风险

| 项目 | 描述 | 建议方案 |
|------|------|----------|
| 推荐套餐唯一性 | 并发更新可能产生两个推荐套餐 | SQLite 部分唯一索引 + 单事务清旧写新 |
| 管理员图片上传 | 通用上传路由权限范围过宽，不应直接作为套餐管理合同 | 新增受计费管理员权限保护的专用路由，底层复用 `uploadService` |
| 支付暂停状态 | 仅靠按钮样式可能仍触发请求 | 模板禁用与事件函数双重拦截，并保留后端 `503` 保护 |
| 排序一致性 | 拖动后部分保存会导致顺序重复或丢失 | 一次提交完整 ID 列表，服务端事务更新 |

## 中风险

| 项目 | 描述 | 建议方案 |
|------|------|----------|
| 广告图可读性 | 图片明暗不可控 | 文案位于独立渐变遮罩区域，不能只依赖图片本身 |
| 动态套餐数量 | 竞品固定 4 卡，但管理员可配置任意数量 | CSS Grid 自动换行，不填充假卡片 |
| 强调色对比度 | 管理员选择的颜色可能导致文字不可读 | 强调色只用于装饰，正文保持固定高对比色 |
| 旧入口兼容 | 顶部按钮和旧查询参数仍指向工作区页面 | 路由重定向测试覆盖旧入口 |

## 需脚本验证

| 项目 | 当前估算值 | 验证方式 |
|------|------------|----------|
| 颜色与对比度 | 目视估算 | WCAG 对比度脚本 |
| 广告图比例 | 桌面 `230 px` 高 | Playwright 三视口截图 |
| 卡片与参考图层级 | 非像素级改造 | 截图 diff + 人工验收 |
| 拖动排序键盘可用性 | 设计合同 | 组件测试与浏览器键盘测试 |

## 低置信度汇总

没有低于 0.6 的实现性判断。竞品字体精确型号与阴影参数不确定，但均不影响业务结构，列入人工复核。
